文档先按一期、二期分开，再按用途分类。文件移动不改变批准状态或业务规则；当前正式业务规则基线为一期 V1.60（明细合同出货时间已在本地 Git 的 PR #62 合并记录中确认；生产是否包含该变更需另核验），二期处于需求建设阶段。

| 目录 | 内容 |
|---|---|
| `一期/requirements/` | 一期正式需求 |
| `一期/manuals/` | 管理员网页、工厂小程序操作手册及随文截图 |
| `一期/project/` | 一期技术设计、开发计划、页面地图、验收、里程碑和历史交接；`work-orders/` 保留 S00–S12 正式工单 |

| `二期/project/` | 二期需求建设计划；后续经确认的技术设计与开发计划按用途放入 |
| `shared/` | 两期共用的小程序复刻和管理员表格视觉规范，保留已有确认及例外记录 |
| `agents/` | Issue 协作与领域文档规则 |
| `reference/` | 共用 Excel 模板、质检和工厂资料参考；保留原路径供现有测试使用 |

二期正式需求稿创建时放入 `二期/requirements/`，目前尚未创建。不为相同公共规则在两期各维护一份副本。
