# Domain docs

本仓库采用单一上下文，根目录 `CONTEXT.md` 是领域术语表；不存在 `CONTEXT-MAP.md`。

## 开始工作前

1. 完整读取根目录 `AGENTS.md`；
2. 读取 `docs/project/一期里程碑与决策记录.md`，确认当前阶段；
3. 按任务读取对应需求、已批准原型、技术设计、开发计划和当前工单；
4. 读取 `CONTEXT.md`，沿用其中的业务术语；
5. 若存在与当前范围相关的 `docs/adr/`，同时读取对应 ADR。

## 资料职责

- 需求文档定义业务范围和验收口径；
- 已批准原型定义页面内容与交互；
- 技术设计定义实现边界；
- 开发计划定义切片顺序与依赖；
- 当前工单定义本次修改范围；
- `CONTEXT.md` 统一领域名词；
- GitHub Issue 跟踪具体执行，不覆盖上述正式资料。

发现资料冲突时不得由 Issue 或 Agent 自行选边，应按 `AGENTS.md` 的规则停止并确认。
