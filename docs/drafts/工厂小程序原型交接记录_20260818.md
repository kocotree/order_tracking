## 二、当前 Bug 清单

### Bug 1：装箱步骤没有按箱装

**表现**：步骤 2（装箱）把所有箱号放在一个下拉框里，所有可发规格平铺展示，没有按每个箱子分别选择内容。

**期望**：应该先选一个箱子，然后为该箱子选择订单和规格→填写数量→确认本箱→再选下一个箱子重复操作。

**涉及文件**：`scripts/pages/create-shipment.js` 的 `renderStep2()` 函数

### Bug 2：创建发货单页面不能滚动到底部

**表现**：进入创建发货单流程后，页面底部被截断，无法滚动看到底部按钮（"下一步"等）。

**原因**：`.detail-page` 的 `min-height: 100dvh` 加上创建发货单内容较多，内容区高度超出时滚动被限制。

**涉及文件**：`styles/create-shipment.css` 和 `styles/task-detail.css` 的布局冲突

### Bug 3：装箱后不能进入下一步

**表现**：步骤 2 的"下一步：凭证"按钮点击后页面没有跳转到步骤 3。

**原因**：事件绑定问题——`#step-next2` 的点击事件绑定了，但 `render()` 重新渲染 DOM 后，之前绑定的事件丢失（因为 `bindEvents` 在每次 render 时重新绑定，但 `step-next2` 在步骤 2 的内容中，需要确认事件绑定时机）。

**涉及文件**：`scripts/pages/create-shipment.js` 的 `bindEvents()` 函数
