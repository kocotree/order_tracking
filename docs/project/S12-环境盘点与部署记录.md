## 3. 本地部署交付

- `deploy/compose.shared-test.yaml` 与 `deploy/compose.production.yaml` 使用不同项目名、内部应用网络、环境文件和 Traefik 路由名。
- API、worker 和一次性 migrate 共用相同 server 镜像；管理员网页通过 Nginx `/api/` 同源代理访问 API。
- Compose 不发布数据库、对象存储或应用宿主机端口；API 与网页仅通过既有 Traefik 网络接入。
- API `/health/live`、`/health/ready` 和网页 `/healthz` 用于内部健康检查；日志使用大小和文件数轮转。
- 发布脚本要求确切 40 位 Git SHA、成功 CI run id、干净服务器工作树、Traefik 网络和 Compose 静态解析；低于建议的 15 GiB 可用空间时输出警告，不再伪装成公司或阿里云强制门槛。
- 迁移前必须先单独确认并验证备份；回滚不默认执行 Alembic downgrade。
- MySQL/OSS 恢复入口只接受名称明确带 `_restore`/`-restore` 的隔离目标。

域名按每个环境一个同源入口收口，不建立独立 API 子域名：

| 环境 | 网页与 API 域名 | API 基址 |
|---|---|---|
| 共享测试 | `order-tracking-test.kktree.cn` | `https://order-tracking-test.kktree.cn/api/v1` |
| 生产 | `order-tracking.kktree.cn` | `https://order-tracking.kktree.cn/api/v1` |

2026-08-28 已只读确认两个域名均解析到目标 ECS，且未出现在现有 Traefik Host 规则中；现有证书解析器为 `myresolver`。这不等于已经创建项目路由或签发 HTTPS 证书。
