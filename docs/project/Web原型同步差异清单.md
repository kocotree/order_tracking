## 保留的差异与待确认项

1. **手工新建和编辑草稿入口未新增。** 当前 `OrderFormPage.vue` 在 `/orders/new`、`/orders/:orderId/edit` 显示“订单日期”；正式需求第 4.1 节规定订单日期不在订单页面展示。当前列表/详情也没有进入这些表单的按钮。原型原先没有该页面，本轮没有把这处冲突扩展进原型；后续需先确定字段展示口径，再同步该表单。不能将本轮描述为所有 Web 路由已完全一致。
2. 原型使用固定示例数据和内存状态，刷新整页恢复。图片使用本地示意图，不能用来验证真实产品图片、鉴权或加载性能。发货凭证仍使用原型示意占位；真实文件和失败重试属于正式前端联调。
3. 飞书登录、获取订单、Excel 解析、下载合同/发货清单/质检附件、服务器权限/并发等外部操作不连接真实服务。模拟交互不等于 API 业务验收，也不模拟每一种网络错误。新建返修单选择文件后仍显示固定解析样例，不读取用户文件内容。
4. 本轮复制的是当前本地检出前端，未确认它与共享测试/线上版本是否相同。无 Playwright、浏览器计算样式、微信开发者工具、真机或真实通知验证。

## 样式和模块边界

- `styles/frontend-baseline.css` 是基准提交中 `admin-web/src/styles.css` 的独立副本，附加三个返修页面和产品图片组件的样式。本轮用已有前端值同步，不重新估算尺寸。原型运行不依赖 `admin-web/` 或 Vue 构建。
- `styles/prototype-adapter.css` 仅处理原型的 `hidden`、弹层开关、原型提示和少量普通 JS 包装节点。
- `index.html` 只加载以上两份样式。旧 `styles/*.css` 保留作历史对照，不再参与页面样式，避免多层覆盖。后续核对原型必须从 `index.html` 实际入口读取样式，不能把旧文件当成当前视觉基准。
- JS 相对导入去掉旧版 `?v=`，使外壳、看板和页面始终复用同一份模拟数据模块。更新后首次查看建议强制刷新；原型入口资源已更新版本参数。
