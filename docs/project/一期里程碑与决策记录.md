# 跟单看板一期里程碑与决策记录

## 1. 这份文件管什么

本文件只回答三个问题：

1. 项目现在做到哪一步；
2. 下一步做什么，做到什么算完成；
3. 哪些过程决策会影响后续阶段。

它不重复业务需求、Agent 操作规则或具体实现方案：

- 业务范围和验收标准：`docs/requirements/一期需求文档.xml`
- Agent 执行规则：`AGENTS.md`、`CLAUDE.md`
- 页面交互：之后批准的原型及确认记录
- 技术实现：之后批准的技术设计方案
- 单次开发范围：当前工单

发生冲突时，业务行为以已批准的需求文档为准；页面交互以已批准的原型为准；技术实现以已批准的技术设计为准。对话、Agent 记忆和未确认草稿不能覆盖正式资料。

## 5. 更新规则

- 阶段完成后，更新“当前状态”和后续步骤，不在这里复制需求正文；
- 新增业务字段、状态、权限或验收口径时，先修改需求文档并由用户确认；
- 改变页面交互时更新原型，改变实现方式时更新技术设计。
