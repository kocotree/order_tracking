## 1. 使用规则

1. `AC-01`–`AC-54` 按 V1.58 第 11 节勾选项的当前顺序编号；需求增删或调整顺序时，本矩阵必须同步更新。
2. 工单实施记录、本地测试或远程 CI 只证明对应实现和自动化检查存在，不能单独把状态改为“通过”。
3. 状态只使用：` 待 S12 验收 `、` 部分真实验证 `、` 通过 `、` 未通过 `、` 接受边界 `。
4. 只有验证人、日期、环境、结果和证据位置都已记录，才能标记“通过”。共享测试通过不等于生产上线或真实外部送达通过。

## 4. 维护方式

- 每完成一项共享测试或真机验收，就在对应行补充验证人、日期、环境、结果和证据位置，不等到 S12 结束后回忆补写。
- 一个 Issue 或 PR 只更新自己实际影响的 AC 行；只有 CI 通过时仍保持“待 S12 验收”。
- 需求、设计或工单发生变更时，先修改对应正式资料，再更新本矩阵；不用本矩阵反向改写业务范围。
