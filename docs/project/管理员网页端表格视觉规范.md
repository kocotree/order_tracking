# 管理员网页端表格视觉规范

> 状态：2026-08-22 用户确认
> 适用范围：`admin-web/` 中的订单看板、订单与发货、产品资料、工厂资料、人员管理，以及后续新增的同类后台列表页。
> 当前实现基线：`admin-web/src/styles.css`。

## 1. 执行要求

1. 新增或修改管理员网页端列表、表格、标题行前，必须先读取本规范、对应已确认原型和当前页面样式。
2. 本规范约束视觉尺寸，不授权增加字段、按钮、页签、状态或业务操作；可见内容仍须遵守页面开工确认门。
3. 已确认原型、当前工单与本规范发生冲突时不得自行取舍，必须先指出冲突并取得用户确认，同时更新本规范。
4. 优先复用现有公共类和 `TableSortButton.vue`，不得为新页面另写一套近似表格样式，也不得用页面内联样式覆盖本规范。
5. 修改后必须在实际桌面浏览器中读取计算后样式并逐页核对；只通过 lint、测试或构建不能代替视觉检查。

## 2. 所有列表页必须统一的尺寸

| 项目 | 固定要求 |
|---|---|
| 页面内容卡片间距 | `14px` |
| 表格卡片标题行 | 高度 `54px`；内边距 `0 16px`；内容垂直居中；底部 `1px` 分隔线 |
| 标题文字 | `18px`；字重 `800`；单行显示 |
| 表头行 | 高度 `40px`；文字色 `#37404b`；背景色 `#f1f3f6`；字重 `800` |
| 单元格边框 | `1px solid #dde1e7`；使用 `border-collapse: collapse` |
| 普通单元格 | 默认左右内边距 `14px`；文本左对齐；超长单行省略，不随意换行撑高 |
| 序号列 | 整列宽度 `52px`；左右内边距各 `8px`；表头和数据均居中；`white-space: nowrap`；不得排序 |
| 排序列 | 只给已确认的业务列增加排序；复用公共双箭头按钮；再次点击在升序和降序间切换 |
| 非排序列 | 序号、图片、选择框、操作等辅助列默认不排序，除非用户另行确认 |
| 横向空间不足 | 保留页面既定 `min-width`，由表格外层横向滚动，不压缩到标题换行或列宽失真 |

“宽度 `52px`”指浏览器中表头单元格的实际渲染宽度，不是只声明 `width`。序号列必须同时落实宽度、内边距、居中和禁止换行，不能再次出现“序号”拆成两行的情况。

## 3. 已确认页面的表格密度与列宽

不同业务表的信息密度不同，行高和普通列宽按下表保留；不得为了表面统一而擅自修改。

| 页面 | 表格 | 最小宽度 | 表格字号 | 表头高度 | 数据行高度 | 已确认列宽（按页面字段顺序） |
|---|---|---:|---:|---:|---:|---|
| 订单看板 | `.dashboard-order-table` | `1120px` | `13px` | `40px` | `40px` | 序号固定 `52px`；其余业务列按现有内容布局 |
| 订单与发货 | `.order-list-table` | `1132px` | `13px` | `40px` | `56px` | `52 / 104 / 164 / 84 / 106 / 110 / 142 / 160 / 110 / 96 / 104px` |
| 产品资料 | `.product-list-table` | `860px` | `14px` | `40px` | `40px` | `52 / 140 / 90 / 240 / 260 / 190px` |
| 工厂资料 | `.factory-list-table` | `1270px` | `14px` | `40px` | `48px` | `52 / 90 / 180 / 290 / 120 / 150 / 150 / 135 / 120px` |
| 人员管理 | `.people-table` | `880px` | `13px` | `40px` | `40px` | 序号固定 `52px`；其余列按当前页列数在固定布局中分配 |

人员管理包含管理员申请、工厂用户申请、管理员账号和用户列表，四页必须共用同一套标题行、表头、序号列和排序样式。

## 4. 排序与序号规则

1. 排序只改变当前查询结果的前端展示顺序，不修改后端数据。
2. 排序后序号按当前显示顺序重新从 `1` 编排；分页页面继续按页码和每页数量计算序号。
3. 新增排序字段前先确认该字段是否属于业务列；不得给序号列和操作列增加排序箭头。
4. 表头文字和箭头必须保持单行，箭头不得挤压序号列或改变已确认列宽。

## 5. 完成前检查清单

- 表格卡片标题行计算后高度均为 `54px`，内边距均为 `0 16px`。
- 标题文字计算后为 `18px / 800`。
- 各表头计算后高度为 `40px`，页面字号、数据行高度和业务列宽符合第 3 节。
- 所有序号列表头计算后宽度为 `52px`，左右内边距为 `8px`，水平居中且不换行。
- 排序箭头只出现在已确认的业务列，点击后升降序状态正确。
- 窄窗口下使用横向滚动，不出现表头换行、列宽互相挤压或操作文字遮挡。
- 记录浏览器对照结果以及任何经用户确认保留的可见差异。
