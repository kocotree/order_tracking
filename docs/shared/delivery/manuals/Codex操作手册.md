# 跟单管理系统｜Codex操作手册

适用：已启用管理员本人。更新：2026-09-30。MCP代码参考v1.1.6，客户端及Plugin正式版本、文件兼容性须按[交付清单](../交付清单.md)核验。普通／最高管理员沿用网页权限，工厂与停用账号无法接入。

## 1. 安装和本人授权

1. 使用维护方交接的跟单管理系统Plugin安装入口，核对名称、版本及对应环境。
2. 在Codex连接对应MCP，使用本人飞书管理员授权，完成浏览器回到客户端流程。
3. 请Codex查询“我在跟单管理系统的身份”，核对姓名、角色和启用状态。
4. 查询一笔已知订单，核对与网页同一环境、同一数据。

没有身份或工具返回时检查服务器MCP是否配置启用、客户端版本和本人网页登录。授权失败提供时间及错误，由维护人员查配置；禁止粘贴Token、Cookie、授权链接或设备码。

网页和Codex共同授权连续30天无业务使用会失效，后台续期不延长该期限。请本人重新授权；账号停用须管理员按正式流程处理。

## 2. 查询

可查询本人、看板、订单／审计、合同、发货／收货、返修周期／附件、工厂、产品／SKU图片、人员申请与通知。说明订单编号、工厂、日期、关键词及范围，查询多页时要求返回总数和筛选依据。

示例：“查询订单415#，列出每个工厂的合同出货时间、下单、已发、未发和派工状态，并给出最近操作记录。”

成功结果应包含业务对象和可核对数据。找不到对象先核对编号、筛选、环境与账号，禁止根据近似名称选另一笔订单。

## 3. 办理业务

| 动作 | 操作顺序 | 成功后核对 |
|---|---|---|
| 草稿／未派工维护 | 查询当前对象→说明逐行工厂、日期、数量→检查预览／变更→明确确认保存 | 当前值、version、审计及汇总 |
| 来源更新／派工 | 查询当前版本→工具生成对应预览→核对变化和校验问题→确认 | 已接受来源或所选明细派工、工厂可见与审计 |
| 收货 | 查原发货与逐箱核对项→保存实际件数→核对差异→确认整单 | 原报保留、收货状态、差额数量只记一次 |
| 退回 | 查单及可退量→指定规格、数量和原因→核对→确认 | 退回记录、原订单已发／未发变化 |
| 订单完成／恢复、撤回派工、删除 | 查询状态及影响→明确目标和原因→确认 | 当前状态、数量摘要、历史审计；依服务器限制 |
| 工厂资料／用户审核／启停 | 查本人权限与目标→给出明确字段／申请／原因→核对→确认 | 工厂绑定、启停状态和审核历史 |
| 返修归档 | 查周期全部完成→核对工厂及周期→明确确认 | 整周期三端隐藏，历史保留 |

示例：“将订单415#第2条未派工明细的合同出货时间改为2026-10-08。先查询当前值并说明影响，待我确认后保存。”

同一动作超时先查询结果和审计，再沿用原预览与幂等键重试。版本冲突重新读取并核对，不强行覆盖。批量有错误默认整批停止；明确授权部分执行时逐项报告成功、失败和未执行。

当前MCP未注册箱贴生成和来货出入数量调整专用工具，这两项按[管理员手册](管理员操作手册.md)和[机器人手册](来货出入飞书机器人操作手册.md)办理。

## 4. 上传质检xlsx

1. 在Codex附上标准质检xlsx，每批1–20份，每份最多20MiB，一份仅一个工厂。
2. 指示“解析这些质检单，列出逐文件的工厂、数量、校验错误；等待我确认创建”。
3. 核对逐份预览；损坏、伪扩展、重复、过期、匹配失败先修正。
4. 全部正确后明确确认创建，检查逐文件结果与返修周期。
5. 工厂端核对任务和附件；通知结果另查。

上传和解析只生成预览。客户端必须实际提供可取回文件参数；若客户端报告文件传输不兼容，保留具体错误并用管理员网页上传。未收到源文件不能声称已经解析。

## 5. 下载文件和查看图片

指定订单＋工厂导出合同，或指定发货单／工厂日期下载清单；返修附件需明确周期及原件。检查工具返回文件名、类型、大小及下载结果，实际打开附件核对内容。

下载地址或描述只能证明服务器提供了下载入口，交付完成需用户实际收到正确附件。文件打不开提供文件名、操作时间和错误，避免反复生成。SKU图片指定准确规格；旧图片版本返回冲突时重新读取产品信息。

## 6. 退出与异常

请求“退出跟单管理系统共同授权”，工具成功后同账号网页及Codex旧凭据失效，微信会话独立。只关闭Codex窗口不会自动撤销共同授权。

| 问题 | 处理 |
|---|---|
| 无权限／账号停用 | 核对本人身份和企业账号，联系管理员 |
| 授权或续期失败 | 本人重新连接，维护人员核对MCP配置及客户端 |
| 预览过期／版本冲突 | 重新查询并生成有效预览，再明确确认 |
| 上传／下载失败 | 核对xlsx、大小和客户端实际文件能力；维护人员检查精确域名白名单 |
| 业务成功但消息失败 | 查询正式业务记录，通知单独重试，禁止重做业务动作 |

接口权限及安全规则见[接口与外部集成说明](../接口与外部集成说明.md)。
