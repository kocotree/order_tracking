# 跟单管理系统｜来货出入飞书机器人操作手册

适用：已启用管理员本人。更新：2026-09-30，代码参考v1.1.6。实际机器人可用状态见[交付清单](../交付清单.md)。用途：根据来货差异凭证核对后登记多货／少货；多货正数，少货负数。确认前的识别和核对文件不会改变正式数量。

## 1. 准备凭证

先在网页用本人飞书账号登录，确保账号启用。在维护人员提供的机器人会话发送清晰JPEG／PNG图片，每张图片对应一个产品名称和货号，可包含多个颜色／尺码及差异。使用真实凭证，不自行猜测缺失名称、工厂、采购或数量；凭证无日期可继续核对。

同一次差异的多图一起发送，机器人按一条消息回复本次新增张数和批次累计张数；后续补发各回复一次。同批相同文件自动跳过并提示，累计只计唯一图片。图片最长20MiB；下载或识别失败时按具体图片重拍、重新发送。工厂及其他角色无法登记。此项及首行嵌图规则由 Issue #217 交付，实际启用以部署版本为准。

## 2. 生成核对表

发齐本次图片后点击“生成核对表”。机器人冻结当前批次，显示识别中；冻结后新图属于后续批次。完成后得到“批次编号_核对表_v…xlsx”，每个工厂一个Sheet，未知工厂放“待确认”。

打开文件逐行核对：

| 列 | 核对内容 |
|---|---|
| 名称 | 实际产品名称，不能空 |
| 规格 | 颜色与尺码直接拼接，例如蔚海蓝M，不能空 |
| 数量 | 非零整数，正多货、负少货，保留每条实际差异 |
| 单价、总金额 | 核对文件展示字段，本流程不生成付款或结算 |
| 采购单号 | 对应精确采购关联，歧义须补充核对 |
| 入库单号 | 凭证可用信息，缺失不自行造号 |
| 图片 | 同一来源原图仅在首条明细放图，后续行图片列留空；各行仍保留来源关联 |

图片日期不作必填。签名和隐藏行标识用于来源验证，不能删除、显示改写或复制成新行。每条登记必须唯一落到工厂、系统订单明细、采购子单及SKU；没有发货单也可登记。

## 3. 修改后回传

1. 使用机器人提供的最新xlsx，在原行修改实际名称、规格、非零数量或采购信息。
2. 需要纠正工厂时，将整行连同隐藏标识移到准确的工厂Sheet；“待确认”必须处理完。允许删除不应登记的来源行。
3. 保留列名、顺序、隐藏标识和签名，不手工新增行、不填公式或错误值；漏识别项重新拍照发送。
4. 保留机器人原文件名，将修改后的完整文件发回本人原会话。
5. 等待“校验通过，最新版本V…”；如返回Sheet、行号或字段错误，按错误修正并用最新表重传。

手工新建工作簿、复用旧版本、外来行标识、重复标识、0／小数／空数量均会被拒绝。请求结果不明先查机器人最新版本，避免错用旧卡片。文件大小不超过20MiB。

## 4. 确认登记

核对表正确后，由原提交人点击对应最新卡片“确认登记”。一条失败即整批不登记；采购／订单匹配仍不唯一时，继续补充凭证和信息，不能根据相近订单确认。

系统覆盖未派工、部分派工、全部派工候选；只有一个候选时允许其未发为0，多候选仍按过滤和合同日期规则选择。规则由系统校验，管理员核对实际采购归属。

成功结果：机器人回复批次正式登记条数及工厂数，网页订单详情出现逐条来货出入，数量与审计同步更新。重复点击同批次只显示已登记信息，数量不会再次生效。工厂可见性和通知依据当前有效派工；未派工记录由管理员先查询，派工后承接到对应工厂任务。

收到“校验通过”只表示文件有效，正式成功需检查“已登记”及订单记录。通知发送失败时业务记录已经生效，通知会单独重试；先核对数量，禁止重复提交同一差异。

## 5. 疑似重复图片

原图与已登记批次相同时，机器人给出旧批次提示。确属同一次差异时停止重复登记；确属另一笔实际差异并有证据，点击“继续核对”后按正常流程核对。不要仅凭数量相同或SKU相同判断两个业务事实可抵消。

## 6. 登记后修正

在网页订单详情展开“来货出入”，定位具体记录，将数量改为正确的有符号非零整数，离开输入框或按Enter后等待保存。核对当前数量、订单汇总及修改记录。系统只应用新旧差额，保留首次登记和调整历史；不提供删除已登记记录操作。

工厂小程序在订单任务“来货出入”折叠区只读查看，按产品分组逐次规格追加。相同SKU多笔差异逐条核对，不能把其中一条改成合计。

## 7. 异常处理

| 回复／现象 | 处理 |
|---|---|
| 无权提交／只能本人确认 | 检查本人网页身份和启用状态，由原提交人办理 |
| 图片读取／识别失败 | 对应图片重拍重发，失败批次不确认 |
| 工厂待确认／名称规格缺失 | 核实实物及来源信息后修改原行、处理Sheet再回传 |
| 多个采购子单／订单不唯一 | 补充精确采购和归属证据，保持待确认 |
| 旧版本／签名／行标识错误 | 下载最新表重新修改，按卡片重新生成；不新建替代表 |
| 卡片无结果／文件未收到 | 记录批次号、时间、具体错误交维护人员查回调、任务和投递 |
| 已登记但通知未到 | 先查网页记录，维护人员仅检查通知，避免重复登记 |

原图、核对表、登记、数量调整和操作人长期留档；故障反馈提供批次号和脱敏现象，禁止复制凭据或私有文件永久链接。
