# 跟单管理系统｜管理员操作手册

操作记录仅展示最近 30 天的内容，Codex MCP 使用同一查询范围。30～180 天记录由具备权限的运维人员从私有归档检索；到期可归档日志会清理。订单、数量等业务事实继续保留，页面没有旧日志不代表业务记录丢失。

适用：普通管理员、最高管理员。更新：2026-10-07；代码参考 `8c924ae`，实际开放功能及客户端版本见[交付清单](../交付清单.md)。本手册覆盖网页业务办理和管理员小程序查询。旧流程截图已从正文移除，原文件保留；配图须使用核对过的当前界面。

2026-10-10：本文已同步 Issue #240 的自动收货及装箱修改流程，随该版本发布后生效；生产转换、小程序发布和业务验收尚未执行。

## 1. 登录与常用入口

打开管理员网页，点击“通过飞书登录”，使用本人企业账号授权。飞书必须返回有效已验证手机号，系统据此建立普通管理员；已有停用账号无法通过重新授权恢复。最高管理员使用同一登录入口。

登录后核对本人姓名。页面提示无手机号、停用或权限异常时，联系维护人员，提供错误及时间。不要借用他人账号。首次管理员微信登录前先完成网页飞书登录，用同一手机号唯一绑定内部管理员。

| 要做什么 | 入口 |
|---|---|
| 看进度、待处理及通知 | 看板、订单列表、通知记录 |
| 保存未派工资料、手动派工、合同、箱贴、完成 | 订单详情 |
| 核对收货、退回、下载发货清单 | 订单与发货 → 发货单列表、发货单详情 |
| 批量质检、返修周期、附件、归档 | 订单与发货 → 返修退回 |
| 工厂合同资料、用户审核和启停 | 工厂资料、人员管理 |
| 查询SKU及图片 | 产品资料 |
| 登记来货出入 | 飞书机器人，见第9节 |
| 在Codex办理管理员业务 | 插件安装、本人授权及操作，见第12节 |

## 2. 查找订单和理解数量

进入订单列表，搜索订单编号、产品名称或颜色/规格，按分类、工厂、跟单人员、合同出货时间、派工状态和业务状态筛选。点击详情查看逐行资料、数量、来货出入和操作记录；发货记录从发货单列表查询，返回时保留列表筛选。

订单详情主数据返回后先显示正文，操作记录、合同状态和来货出入分别加载。合同状态和工厂选项加载期间，对应操作暂不可用；某一区块加载失败时按提示刷新页面，刷新前先保存尚未保存的编辑。

下单是该明细要交的数量，已发包括来源初始已发及后续有效发货、收货差额、退回和来货出入；未发逐行最低为0，空值表示无法判断。派工状态与业务状态分别查看。合同出货时间按明细保存，同订单可能有多个日期。

来源订单明细中的已发／未发数量在未派工、已派工和已完成阶段均可修改，修改后点击标题行“保存”。已发为非负整数，可超过下单量；未发为不超过下单量的非负整数，两者联动。已派工修改保留原始基线并记录调整差额；已完成订单调整后欠货会恢复未完成或已逾期，交足后需再次确认完成。工厂和日期仅未派工明细可改。

## 3. 自动同步与未派工维护

系统每20分钟发现新订单、更新草稿／部分派工订单未派工资料，并按工厂自动派工。工厂、产品、合同出货时间、跟单集合和数量有效，工厂启用且有审核通过并启用的用户时，才可派工。同一厂一条无效会阻止本厂整组，其他工厂独立判断。

来源合同出货时间取飞书“合同出货时间”减4个自然日；人工填写最终业务日期，系统直接使用。人工保存的字段受覆盖保护，修改工厂资料后点击“更新未派工明细”也不会覆盖已人工保存的工厂，须在对应明细直接选择正确工厂并保存。

新来源订单任一明细原始进度低于95%或数量未知时，保留完整订单；全部明细均达到95%则跳过新建。找不到来源订单时联系维护人员查最近同步和筛选依据。

1. 在订单详情找到未派工行，核对产品、采购关联和工厂。
2. 选择工厂，填写合同出货时间、已发或联动未发数量。已发填0有效；人工清空日期有效，但日期缺失阻止派工。
3. 点击“保存”，等待成功；刷新确认已保存值及汇总正确。
4. 要读取最新来源时，点击“更新未派工明细”，核对预览，再确认更新。
5. 明确要派工时，勾选未派工行，点击“派工（已选…条）”，核对校验结果，全部通过后确认。

成功结果：所选明细显示已派工，工厂可见对应任务，操作记录可查。人工保存的工厂、日期、已发／未发覆盖不会被来源自动更新；已派工基线保持。显示有未保存修改时先保存，不能带未保存值确认更新或派工。

## 4. 手工草稿、撤回派工与完成

手工草稿页保留在网页`/orders/new`，当前订单列表没有新建按钮，日常使用由维护人员提供该页面链接。填写唯一订单编号、跟单人员、产品规格数量及工厂分配，保存后工厂不可见；核对各规格工厂分配合计及日期，在详情点击“发布订单”确认。来源明细订单使用第3节逐明细派工流程。

要撤回派工，在订单详情点击“撤回派工”，按弹窗选择可撤回工厂并确认。成功后仅该厂明细恢复未派工，其他厂不变，历史记录保留。人工撤回会暂停对应明细自动派工；后续需要恢复时补齐资料并手动派工。没有可撤回项时核对已有业务状态，按页面提示处理。

全部明细派工且全部交足后，点击“确认订单完成”，核对摘要后确认。仍欠货无法完成。完成后发生有效退回会自动恢复；补发交足后再次确认。需撤销完成时点击“撤销完成”并按弹窗核对原因及影响。

## 5. 导出加工合同和箱贴

### 加工合同

1. 打开订单详情，点击“导出加工合同”。
2. 选择工厂，检查产品、正整数下单数量及工厂代码、法定名称、地址、法定代表人。
3. 导出并下载xlsx，打开检查名称、颜色、尺码、数量、图片及文件名。
4. 需要填写加工单价时，在Excel中填写，核对金额公式。

首次合同可包含已匹配工厂的未派工明细，合同出货时间为空也可导出。首次合同编号、签订日期和明细快照固定，重复下载保留原内容。新合同按产品＋颜色分组，尺码数量逐行保留；历史合同按原布局。图片取同产品同色内SKU升序首张可用图，不能用其他颜色代替。合同单价和金额仅在导出文件填写。

### 箱贴

订单详情点击“导出箱贴”，按工厂、产品、颜色选择分组。可导出行点击导出，下载并核对图片、名称、颜色与打印内容；不可导出原因先处理。首次导出固定分组快照，来源图片之后更新不自动改写既有箱贴。Excel/WPS打开及实际打印结果须由业务核对。

## 6. 发货清单和收货核对

进入“订单与发货 → 发货单列表”，搜索关联订单或发货单号，按工厂、收货状态筛选。列表当前行“下载”导出该工厂当天全部有效发货的汇总，文件为“工厂名称_YYYY-MM-DD_发货汇总.xlsx”；详情“下载发货清单”只导出当前单。导出保留工厂原报装箱事实，包含发货明细和汇总。

列表下载的汇总 Sheet 顶部显示工厂、发货日期和总件数，列为日期、名称、颜色/规格、数量、单价、总金额、采购单号、入库单号。日期按“10.6”显示并合并，同名合并；采购单号来自关联明细，多个去重并列。单价、总金额、入库单号留空供填写，末行汇总数量。详情下载格式保持原样（Issue #219；上线以发布记录为准）。

汇总 Sheet 全部内容水平、垂直居中；表头至底部汇总行添加黑色细内外框线，包含空白填写格，日期和名称的合并区域内部无分隔线（Issue #229；上线以发布记录为准）。

1. 打开发货单详情，核对发货单号、日期、工厂、原报明细和凭证。
2. 在“装箱明细”逐箱逐规格输入实际收货数量，可填0；规格填错时，从下拉框选择同厂同产品已有订单派工规格，再核对数量。
3. 核对合计和每条差异，点击“保存”，等待“订单发货数量已同步”。
4. 查看差异、订单数量和操作记录；仍有错误可继续修改并保存，每次只计入相对上次的差额。

工厂提交后自动收货，无需点击确认，也不发送收货通知。保存修改即时更新订单数量并通知工厂；原报装箱及下载清单保持原报。发生退回后装箱只读。保存网络结果未知时保留页面并用“保存”或“重新读取核对”重试原请求；版本冲突会保留输入，核对提示后重新读取最新值再填写。

## 7. 按发货单退回和工厂撤回

按原单退货时，在发货单详情“发货明细”右侧点击“退回”，勾选规格，填写不超过可退量的正整数及退回原因，核对后确认。支持部分规格、部分数量或全部可退数量。成功后保留退回记录，对应订单已发减少、未发增加；工厂从正常订单任务登记补发。

工厂可自主撤回首次正式提交未满7天、没有退回的有效发货单。撤回立即冲销当前生效数量，修改重新提交后再计入，原单号保持；重提不延长首次7天期限，恰好满7天禁止撤回。管理员查看状态与历史；已有退回禁止修改装箱及撤回。历史撤回审批记录只用于追溯。

## 8. 质检返修

1. 进入“返修退回”，点击“新建返修单”，点击或拖入标准质检xlsx，可一次多份。
2. 上传前在原文件核对工厂、规格、数量；每份只属于一个工厂，单批最多20份、单份20MiB。页面逐文件显示解析通过或错误，不展开质检明细。
3. 点击“确认创建”逐份创建解析通过的文件，失败文件保留错误；修正后重新上传。解析通过尚未创建任务，须检查每份“创建成功”的结果。
4. 回返修列表，按工厂和返修周期查找，打开详情核对质检原件和各规格仓库退回、返修、报废及累计返回数量；网页周期详情不展示逐批发回历史。
5. 整周期全部返回并显示已完成后，点击归档，核对周期再确认。归档后三端隐藏，数据与日志继续保留。

周期为每年2—7月及8月—次年1月，未返完继续原周期。工厂提交返修＋报废发回立即计进度，系统按来源顺序分配，全部返回自动完成。质检返修不改变正常订单进度；原发货退回补发使用第7节。

## 9. 来货出入登记和修正

本节为 Issue #239 配套操作说明，随该功能发布后生效；生产发布和实际文件往返另行验收。设计见[增量方案](../../../二期/project/来货出入自由整理与多文件登记技术设计.md)。

**入口：**本人已启用管理员账号 → 飞书“订单跟单管理系统”机器人。

**发图 → 生成核对表 → 核对／回传 → 确认登记 → 网页查验。**

### ① 发图，生成核对表

先用本人飞书账号登录管理员网页，再向机器人发送清晰JPEG／PNG图片，每张不超过20MiB。每图对应一个产品，可含多个规格；同批相同文件自动跳过。

发齐本次图片 → 核对累计张数 → **生成核对表**。生成后新图进入下一批；文件按工厂分Sheet，同图仅首行放图片。

### ② 核对，修改后回传

逐行核对**工厂、名称、规格、数量、采购单号及原图**。规格为颜色直接连接尺码；**多货为正、少货为负，数量为非零整数**。归属不明先核实。

下载后可改名、增删移动明细、合并不同批次或按工厂拆分文件。将本次全部 Excel 一起放入机器人私聊输入框，一次发送。机器人按这条消息中的完整附件集合统一核对。

- 保留八列名称和顺序；工厂 Sheet 名须与系统一致。登记读取名称、规格、数量、采购单号，这些列使用最终值，不能填公式；采购单号建议文本格式。
- 不要求原文件名、隐藏标识或签名。价格、金额、入库单号及图片保留在上传原件中，不参与数量登记。
- 每次最多30份、每份100MiB，全部文件累计100MiB、解压累计100MiB、总明细5000行。单份最多30个业务Sheet。
- 新上传会替换此前整个待登记集合，旧确认立即失效。报错时按**文件名／Sheet／行号**修正，重新发送完整集合。已正式登记的数据继续保留。
- 出现疑似重复时，使用飞书回复功能回复该审核清单，例如“第1条跳过，第2条作为新记录登记”或“疑似重复的全部跳过”。决定不完整或含糊时不能登记；每次决定后使用最新清单。
- 无修改时可在生成表卡片点击“核对登记”，同样先检查疑似重复，再展示最终确认。

### ③ 确认登记，查验结果

原提交人点击最新卡片**“确认登记”** → 检查正式登记条数及工厂数 → 网页订单详情展开**“来货出入”**，逐条核对采购单号、产品、规格和数量。

**任一文件或明细失败，本次全部不登记；生成表、校验通过及文字决定尚未生效。**确认前核对文件清单、各厂条数、多货／少货数量和跳过数；全部跳过会完成零条登记。系统须唯一匹配订单明细、采购子单及SKU；没有发货单也可登记。未派工记录由管理员查询，工厂按当前有效派工查看。

提示图片曾登记时，先查旧批次；确属另一笔差异且有凭证，才点**“继续核对”**。已登记但通知未到，先查网页记录，勿重复登记。

### ④ 登记后修正

要更正已登记数量，修改数量框并离开输入框或按Enter，等待保存成功，核对汇总及操作记录。多货正数、少货负数，只接受非零整数；同SKU的不同记录逐条保留，修正只作用于新旧差额，不提供删除按钮。版本冲突刷新后重新核对。未派工记录由管理员可查，工厂可见性按当前有效派工判断。

## 10. 基础资料、人员和通知

工厂资料核对名称、供应商编号、合同代码及法定资料。新增供应商编号必填、自动大写并唯一；编辑时编号只读。工厂名称用于来源严格匹配。填写联系人用于申请审核，不填写已取消的银行、代理人或别名字段。

工厂用户申请详情核对姓名、电话、职位、申请工厂及联系人，批准时确认绑定工厂；拒绝必须填原因。普通管理员可办理工厂申请和工厂用户启停；仅最高管理员可管理普通管理员启停。

产品资料来自聚水潭七类启用产品，网页只读。图片问题按货号、SKU、颜色/规格、时间和现象提供证据，由维护人员处理来源和缓存。

新单同步和“更新未派工明细”遇到产品匹配失败，会自动按产品编码补拉聚水潭整款资料并重新匹配，图片随后异步缓存。查不到或资料仍不一致时继续显示异常。手动更新在预览时补齐产品库；取消预览保留补齐的产品资料，订单明细仍需确认才更新。

网页顶部、看板和通知记录可查通知，点击前往相应业务详情；通知记录可切换“全部／未读”，右上角扫帚按钮将本人通知全部标为已读。管理员小程序“我的”可查看通知中心及发起微信提醒授权；授权拒绝不阻断正常登录和站内查询。合同出货提醒按角色走飞书／微信，真实外发受当前配置与平台授权影响。

### 合同出货提醒

以**合同出货时间**为准，仅提醒仍有未发数量的有效派工明细。

| 提醒节点 | 接收人员 |
|---|---|
| **D-10、D-5、D0（当天）** | 对应订单跟单人＋对应工厂已启用用户 |
| **D-3** | 对应订单跟单人＋对应工厂已启用用户＋**煎饼、核桃**；同一人去重 |

管理员通过**飞书**接收，工厂用户通过**微信订阅消息**接收。

**收到提醒 → 查看订单详情 → 核对工厂、合同出货时间及未发数量 → 跟进出货。**

## 11. 管理员小程序

首次微信手机号绑定同一管理员后，可查看订单／进度、发货概览与规格／逐箱／凭证／备注／记录、返修周期及质检附件、通知。小程序不显示收货状态或确认人、时间。装箱明细修改仅在管理员网页办理；其他维护、导出和人员办理使用网页或对应已注册MCP工具。

出现与网页数据不一致时，先核对账号、环境、筛选和刷新时间，再记录订单／单号及现象交维护人员。退出仅清理相应会话，身份绑定保留；网页与Codex共同退出规则见第12节。

## 12. 通过 Codex MCP 办理业务

**安装 → 本人授权 → 说明需求 → 核对结果。**普通／最高管理员沿用网页权限，工厂及停用账号无法接入。

### ① 安装与授权

1. Codex → **插件 → 添加 → 添加插件市场**。
2. 来源填写 **`kocotree/order-tracking-plugin`**；Git引用 **`main`**；稀疏路径**留空** → 添加市场。
3. 安装并启用**“跟单管理系统”** → **开启新对话**。
4. 发送“用跟单管理系统查询我的账号” → 按提示用**本人飞书授权** → 核对身份，再查一笔已知订单。

### ② 说明需求，核对后执行

选跟单管理系统工具，写清**订单号＋工厂＋具体动作＋日期／规格／数量**。核对当前值和预览后确认；信息不全先补齐。

| 用途 | 示例／操作 |
|---|---|
| 查询 | “查询465#各工厂的合同出货时间、已发、未发及派工状态。” |
| 日期与派工 | “465#订单的千与工厂，合同出货时间为2026-10-20，请填写该日期并完成该工厂派工。”日期按实际业务替换 |
| 核对查询、退回、完成及撤回派工 | 查当前有效数量 → 指定范围、数量或原因 → 核对影响 → 确认 → 查结果；装箱修改用网页 |
| 工厂、人员、通知 | 可查询资料、维护工厂、审核申请、启停账号及处理通知；按本人权限执行 |
| 合同与发货清单 | 明确订单＋工厂或发货单／工厂日期 → 下载 → 打开核对内容 |
| 质检返修 | 上传.xlsx（每批≤20份，每份≤20MiB，一份一家工厂）→ 解析 → 核对逐文件结果 → **确认创建** → 查返修周期；全部返回后可确认归档 |

**解析通过仍须确认创建；下载后打开核对。**客户端文件传输失败时，质检文件可使用网页上传；未收到文件时不能继续解析。

### ③ 查验与异常处理

回网页核对**明细、日期、数量、状态及操作记录**。指定工厂派工成功后，其他行未派工时整单仍为部分派工。

- **超时先查结果**，避免重复提交；预览过期或版本冲突时重新查询、核对。
- 批量报错先处理；明确确认部分执行时逐项核对成功、失败和未执行项。
- **装箱修改、箱贴、来货数量更正用网页；来货发图登记见第9节。**
- 授权失效由本人重新连接；共同授权连续30天无业务使用会失效。账号停用联系管理员。
- 请求**“退出跟单管理系统共同授权”**并成功后，同账号网页及Codex旧凭据失效；微信会话独立。关闭Codex窗口不会撤销授权。

## 13. 遇到问题

| 现象 | 自查及提供的信息 |
|---|---|
| 找不到订单／工厂任务 | 清除筛选，检查派工状态、账号所属及自动同步；提供订单号和工厂 |
| 保存／确认失败 | 阅读具体问题，刷新当前版本；结果不明先查原单和日志；提供requestId／时间 |
| 图片／文件打不开 | 核对登录、文件归属、实际SKU和网络；提供文件名及错误，不共享私有链接 |
| 数量不符 | 提供订单明细、原报、收货、退回、来货及修改记录，由维护人员逐项核对 |
| 通知未到 | 先查站内和业务结果，再核对订阅／外发配置；不重复执行业务提交 |
