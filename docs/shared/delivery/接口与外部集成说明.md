# 接口与外部集成说明

## 飞书出货阶段回填（Issue #227）

无新增客户端 HTTP 接口。后端复用订单来源应用身份，仅写已批准的阶段数字列和“出货总数”公式。新增字段带持久化 `client_token`，不确定结果先重查；字段更新保留完整可写属性，写前核对公式基线，写后回读。记录更新仅发送目标单元格，按绝对值覆盖；身份列、其他来源字段及其他公式不写。

接口依据为官方[创建字段](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-field/create.md)、[更新字段](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-field/update.md)、[列出字段](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-field/list.md)、[更新记录](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-record/update.md)。字段按分页完整读取；公式使用原生字段引用，初始表达式从受控核验取得，不实现通用公式 parser。权限、公式类型兼容性与真实读回尚待授权环境验证。

配置、日志及原任务重试见[部署运维](部署与运维手册.md#出货阶段汇总回填issue-227)。PR #228、#232 已合并；本次文档核对未执行真实飞书写入。

代码核对：2026-10-07，`8c924ae`。HTTP 完整字段、参数、响应类型及请求头以[OpenAPI](../../../server/openapi/openapi.json)为准，客户端生成类型来自同一文件。本文记录接入方式和调用约束，避免重复维护逐字段接口副本。

## 地址与协议

| 入口 | 用途 | 权限 |
|---|---|---|
| `/api/v1/` | 网页、小程序业务 API | 网页会话或小程序 Bearer；逐接口核验角色与工厂 |
| `/health/live`、`/health/ready` | 进程存活、数据库等依赖就绪 | 运维健康探测 |
| `/mcp` | 管理员 MCP，配置后注册 | 本人 OAuth access token，`order_tracking.admin` scope及正确 resource |
| `/.well-known/oauth-authorization-server` | MCP OAuth 元数据 | MCP 启用时注册；不列入业务 OpenAPI |
| `/oauth/authorize`、`/oauth/token`、`/oauth/revoke` | 授权、兑换／续期、撤销 | 预登记客户端、resource、PKCE 和当前管理员 |
| `/api/v1/integrations/feishu/events` | 飞书消息与 URL verification | 平台校验、消息去重、启用管理员身份 |
| `/api/v1/integrations/feishu/card-actions` | 来货出入卡片操作 | 同上，并核验提交人和核对表版本 |

生产和共享测试各自使用独立 HTTPS 域名。网页与 API 共用环境域名；小程序合法请求域名、微信状态和 MCP公开 resource必须匹配目标环境。实际地址和启用状态在[交付清单](交付清单.md)登记。

## 身份、并发与错误

网页使用 `ot_web_session` HttpOnly Cookie，受 CSRF 保护的写接口传 `X-CSRF-Token`。小程序以 `Authorization: Bearer …` 传本端会话。写接口是否需要 CSRF、幂等和版本参数，逐项查看 OpenAPI；禁止把网页 Cookie 当作 Agent凭据。

有 `version` 的修改提交读取时版本；有 `previewId` 的确认只能使用同一操作人的有效预览和订单版本。有 `Idempotency-Key` 的接口或 MCP `idempotency_key` 参数，同一次业务动作重试沿用同一键；不同业务动作生成新键。版本冲突刷新最新内容，再重新核对，禁止强行覆盖。超时先查询目标记录和审计，确认结果后再重试。

常见错误响应包含 `code`、`message`、`requestId`；校验错误可能另有问题明细。记录 HTTP状态、错误码和 requestId：401检查会话；403检查角色、停用及跨厂权限；404检查对象可见性；409检查版本／状态／幂等冲突；422核对请求字段。未知失败以实际响应和后端日志为准，不自动转换成成功。

列表筛选、排序和分页由服务器处理；页大小按对应接口范围传入，不能以单页数量代表全量。业务日期为日期类型，登记及审计时间为时间戳；页面时区与业务日期分开核对。

## HTTP 业务分组

下表为导航前缀，具体方法和完整路径见 OpenAPI 与对应[API 路由](../../../server/app/api/)。

| 分组 | 入口 | 调用要点 |
|---|---|---|
| 身份 | `/auth/feishu/*`、`/auth/refresh`、`/auth/logout`、`/mini/auth/*`、`/me` | 飞书登录授予普通管理员；微信手机号绑定；各终端凭据分开 |
| 订单 | `/admin/orders`、`/orders` | 草稿／明细维护、来源预览确认、派工预览确认、撤回、完成与恢复 |
| 来源历史 | `/admin/import-runs`、`/admin/import-candidates` | 旧入口保留在契约中需结合实际路由退役状态判断；当前自动同步不开放候选导入页面 |
| 合同 | `/admin/orders/{order_id}/contracts`、`/admin/contract-exports/*` | 选择订单＋工厂，首次固定快照；下载再次鉴权 |
| 箱贴 | `GET /admin/orders/{order_id}/box-labels` | 读取候选分组及不可导出原因 |
| 箱贴生成 | `POST /admin/orders/{order_id}/box-labels/{group_id}/exports` | 首次固定组快照；响应给 exportId 和下载地址 |

| 发货与收货 | `/factory/shipments/*`、`/admin/shipments/*` | 工厂草稿／提交／自主撤回，管理员收货保存确认及退回；Issue #222 删除详情 `voidRequest` 旧审批字段，旧申请及审批路由保持不存在 |
| 返修 | `/admin/repair-previews`、`/admin/repairs`、`/admin/repair-periods`、`/factory/repairs/*` | 上传先预览，确认才创建；工厂周期发回；整周期归档 |

| 来货出入调整 | `PATCH /admin/orders/{order_id}/incoming-differences/{record_id}` | `quantity`非零整数、`version`当前值；记录差額流水与审计 |
| 基础资料 | `/admin/factories`、`/admin/products`、`/admin/users`、`/admin/factory-applications` | 产品只读、工厂及工厂申请办理；普通管理员启停需最高管理员 |
| 通知与文件 | `/admin/notifications`、`/mini/notifications`、`/files/*`、`/shipment-files/*` | 权限重验；私有文件不返回公开 OSS地址 |

## MCP 接入与能力

实现入口：[MCP server](../../../server/app/mcp/server.py)、[OAuth](../../../server/app/modules/identity_access/agent_oauth.py)。管理员本人通过飞书建立共同授权，预登记公开客户端使用 PKCE `S256`，回调限制于允许的本机 callback路径，授权请求有效期5分钟。access token有效15分钟，refresh token轮换，重放旧刷新凭据会撤销对应授权。

网页和 MCP 共用管理员授权活动窗口：连续30天无业务使用后失效。有效业务请求更新活动时间，后台静默刷新不延长窗口。退出共同授权使网页和 MCP旧凭据失效；微信会话单独管理。每次工具调用重新核验用户启用状态，不能沿用停用前权限。

| MCP 模块 | 已注册能力 |
|---|---|
| 通用 | `get_me`、`get_dashboard`、`list_orders`、`get_order`、`get_order_audit`、`logout_shared_session` |
| [订单](../../../server/app/mcp/order_tools.py) | 新建／更新／发布草稿、明细保存、来源更新和派工预览确认、工厂撤回派工、删除、完成／恢复、合同生成下载、同步和候选历史查询 |
| [发货](../../../server/app/mcp/shipments.py) | 发货列表／详情／日汇总、清单下载、收货读取／保存／确认、退回 |
| [返修](../../../server/app/mcp/repairs.py) | 周期与详情、批量质检 xlsx预览／确认、附件下载、整周期归档 |
| [资料](../../../server/app/mcp/directory.py) | 工厂、产品及 SKU图片、人员、工厂申请审核、通知与标记已读 |

当前工具注册未提供箱贴生成和来货出入数量调整专用工具；这两项使用[管理员手册](manuals/管理员操作手册.md)中的网页入口。已注册能力应逐个按服务器返回的工具契约调用，避免根据页面名称推测工具名。MCP工具返回成功与 Codex客户端实际收到文件分别验收。

## Agent 文件往返

质检上传 `upload_repair_workbook(files)` 声明 `openai/fileParams=["files"]`，每个文件包含 `download_url`、`file_id`、`mime_type`、`file_name`，仅 `.xlsx`。文件必须通过允许域名的 HTTPS传入，最长20MiB；下载验证公开 DNS、固定解析目标并拒绝重定向，不转发用户 Cookie／Authorization。允许域名使用精确主机名，不能放通通配域名。源文件元数据、下载失败和格式错误均应阻止确认创建。

合同、清单和质检附件下载描述包含 URL、文件名、MIME、大小及摘要。Agent需按工具契约取回文件并展示真实附件；只返回下载描述不能证明用户已收到。客户端不支持原生文件参数或下载时，应报告具体限制，按网页入口完成同一业务操作，禁止伪造附件或任意补域名白名单。实现见[文件适配](../../../server/app/mcp/files.py)。

## 外部系统配置与核验

Issue #215 的订单产品补拉复用应用凭据的聚水潭 `sku.query`：现有产品编码以 `sku_ids` 精确查询，校验 SKU 身份后按 `i_ids` 分页读取整款。自动新单、自动未派工更新及手动预览严格匹配失败时触发；网络读取在订单写事务外，产品同步提交后再匹配，图片继续由 sync worker 缓存。无新增字段配置或定时任务。手动确认应用和派工不再次读取上游。部署及真实来源验收以对应发布记录为准。

| 系统 | 数据／能力 | 必须核验 |
|---|---|---|
| 飞书登录 | 企业身份、已验证手机号、头像 | OAuth回调、应用发布、手机号权限、最高管理员白名单 |
| 飞书订单 | 读取订单最终采购主／子单、日期、工厂、跟单人员；授权启用后回填阶段出货数字与总数公式 | 来源字段只读；回填字段范围、历史准备、公式基线及写后回读须核验 |
| 聚水潭 | 七类启用商品、每 SKU图片、采购 `qty/inQty` | 权限、Token续期、限流、分页与精确采购子单；不以库存总量代替采购量 |
| 飞书机器人 | 图片／文件消息、卡片、回传及回复 | 复用订单应用凭据，机器人和消息／资源权限、事件与卡片两个回调、签名／加密、应用已发布及资源可下载 |
| 固定识别模型 | `qwen3.5-flash`＋仓库固定 prompt | [vision适配](../../../server/app/adapters/vision.py)、模型密钥、网络、固定离线样例；结果只作候选 |
| 微信 | 登录手机号、角色订阅模板、通知 | AppID环境、合法域名、5类模板配置、`trial/formal`及授权消耗／送达 |

所有真实配置、来源资源标识和凭据留在受控配置中，交付文档只记录配置名称、用途、责任方和脱敏结果。具体配置分组与诊断见[运维手册](部署与运维手册.md)，实际联调见[验收记录](验收记录.md)。
