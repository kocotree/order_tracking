## 每次发布必填

| 字段 | 要求 |
|---|---|
| 版本与SHA | 不可变标签、精确40位SHA、发布时间和执行人 |
| 变更 | 关联Issue／PR、业务影响、配置／迁移要求和已知问题 |
| 配套客户端 | 小程序提交与正式版本、Plugin版本及兼容性 |
| 工作流 | 同一SHA的main CI、Release及deploy结果与链接 |
| 运行 | ECS镜像version／digest／revision、schema、健康、与该版本匹配的worker角色（当前代码四角色）和外部登录 |
| 验收 | 环境、用例、实际结果、验证人、证据及失败Issue |
| 恢复路径 | 上一可用版本、schema兼容评估、备份批次与最近恢复证据 |

失败版本仍记录失败阶段、实际环境状态、处理动作与复验，不以更改标签或删失败记录掩盖问题。生产版本恢复、数据恢复、真实通知和小程序发布分别取得对应操作授权。
