## 实现与文件范围

- `server/app/db/models.py` 和迁移 `20260928_0047_sku_images.py`：SKU 独立图片来源、对象、状态、错误、修订号与图片来源时间。只新增字段；旧 products 图片字段留存，无公共图片批量复制，无历史数据重写。
- `product_sync/service.py`：全量、增量、定向同步共用图片更新路径；任务按 SKU＋修订号去重；下载前和回写时检查当前来源及修订号，回写加锁。图片来源变化先清空当前引用；缺图为 missing，失败为 failed，可重试。旧产品任务直接结束，不下载或回写。
- `adapters/product.py`：校验图片后按内容 SHA-256 保存。同内容共用对象，不同内容使用新键，保留历史文件。
- `api/products.py`、`mcp/directory.py`、OpenAPI 和两端生成类型：图片读取改用 variantId，版本校验和管理员权限保留。网页原组件直接消费每行 imageUrl，无页面布局或交互扩展。
- `order_import/service.py`、`orders/service.py`、`orders/dispatch.py`、`contracts/service.py`：候选、新建订单、首次派工及合同首次快照取对应 SKU 的 cached 图片；待缓存、缺失、失败不取旧引用。已有订单及合同快照保持原值。
- `product_sync/backfill.py`、`scripts/enqueue_product_sync.py`：新增 `images` 运维模式，按本地去重货号定向取全部分页，逐 sku_id 核对。默认预览，digest 提交时重新读取；逐 SKU 事务、行锁、图片来源时间检查及审计保护重复执行和并发。只改图片字段，不推进全库游标。
- `adapters/private_files.py`：区分确实不存在的对象和访问失败；补齐仅对来源匹配、可读且图片校验通过的对象计入复用。404/损坏可下载，403 等失败明确报告。
- 正式资料同步至 CONTEXT、一期需求、技术设计、数据字典、API 使用说明及 server README；测试覆盖图片隔离、乱序、权限、历史快照和迁移。

## 补齐操作与后续验收

命令入口及结果字段见 [server README](../../../server/README.md)。预览会查询真实来源并读取 OSS，生产执行仍须单独授权；当前会话仅以隔离库及模拟适配器测试。`cached` 数据库状态不证明对象可读，不能据本地测试宣称生产复用率。

用户提供的生产背景为 OSS `403 UserDisable` 尚未恢复，本轮未重试生产访问。恢复后需按发布确认门执行迁移和服务更新，再独立批准补齐预览/写入及业务验收。迁移后尚未补齐的 SKU 为 missing；完整补齐前相应页面及新快照可能无图，历史快照仍保留原引用。

本项逐 SKU 采用聚水潭返回的 `pic`，允许同色不同尺码图片不同，不执行同色图片一致性校验。颜色提取与代表图选择只在 #186 箱贴、#189 合同导出时处理；其分组内按 SKU 编码固定升序选择首个有可用图片的 SKU，不改变各 SKU 原图。合成多颜色/尺码场景已验证；生产仍需核对每个 SKU 与其来源图片的对应关系及真实对象可用性。
