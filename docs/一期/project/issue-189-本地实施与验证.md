## 实施

- 新合同保存渲染版本 v3，复用 v2 工作簿文件和固定文案。历史合同仍按自身保存的 v1/v2 版本及首次快照渲染。
- 从组合原文提取颜色；产品身份使用 `productId`，非连续同组明细排到相邻行。各规格、数量和公式逐行保留，货号、品名、图片区按组纵向合并。提色失败的明细独立成组。
- 首次新合同从各 SKU 当前 `cached` 图片引用取值，不继承旧订单行可能错误的产品级图片快照；每个 SKU 原图引用保存在合同明细快照内。组内按 SKU 编码升序固定首个有图引用作为代表，整组缺图留空。已选引用的 OSS 读取或图片校验失败会使导出失败。
- 只读聚水潭抽样确认了 `冰川蓝110`、`黄色;S`、`麻灰;110/60` 和 `粉色;` 等组合形态；另以仓库既有 `藏青,54`、`米色 / 52cm` 和字母尺码样例建立回归。无法从原文明确识别颜色的输入不猜测。
