# Issue #85 小程序登录文案与失败重试

2026-09-10，基于 main `50b747e`（对应 main CI 成功），独立分支 `codex/issue-85-mini-login`。用户要求两角色登录按钮改为“手机号快捷登录”，并排查提交审核时已勾选协议却提示同意协议的现象。

## 已证实问题与修改

管理员和工厂共用 `miniprogram/pages/auth`。原手机号回调将协议状态和身份绑定凭证合并判断，任一不满足均提示同意协议；身份识别失败后凭证为空，但仍可打开手机号授权且没有身份重试路径。页面回调测试先在原代码失败，修正后通过。

共用按钮和两角色原型按钮文案已同步；协议未勾选才显示协议提示，缺少身份凭证时原按钮重新识别，识别完成后再次点击触发原生手机号授权。识别前清除旧凭证、请求期间拦截重复操作。既有权限、账号绑定、手机号授权和角色跳转不变，无后端与数据库变更。
