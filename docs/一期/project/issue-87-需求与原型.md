## 已确认布局及本轮评审内容

- 保留顶部三列两行概览及订单执行状态，订单列表不增加派工列或页签。
- 明细标题左侧为“订单明细”和“已派工 X/Y 条 · 派工进度”，右侧更新未派工明细、派工（已选 N 条）。
- 明细列：选择、序号、产品编码、产品名称、颜色/规格、工厂、派工状态、合同出货时间、下单数量、已发数量、未发数量、发货进度。全部派工隐藏选择列与两按钮。
- 已派工行只读；未派工行可选择，不在状态下堆积错误文字。点击派工，先确认来源变化，再展示所选校验结果；任一错误整批不提交。
- 用户最新确认：只允许在未派工行修改合同出货时间，产品编码、名称、规格、工厂和所有数量均只读，不提供手动匹配工厂入口。其他来源资料在飞书修正后通过更新未派工明细同步；工厂资料/账号问题在对应资料管理中处理。日期输入失焦更新当前原型数据，不代表生产自动保存协议已设计。示例固定跟单人为松子，未模拟全部来源脏数据和管理员修正流程。
- 派工校验弹窗列出明细、工厂、校验结果；有错禁用确认，允许关闭/取消/ESC，返回保留选择。
- 更新弹窗列出明细、字段、当前值、来源新值；确认才生效，取消不更新。人工修改的日期保留，已派工明细不参与更新。
