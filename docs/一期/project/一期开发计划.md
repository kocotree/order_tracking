## 自动同步专项验证

#187 实现已进入 main；核验当前环境时覆盖：

- 来源发现按严格 95% 门槛及已确认未知数量规则处理，完整订单与来源身份稳定；存量候选人工值及日志承接。
- 已完成订单不更新，已派工明细不覆盖；人工工厂、日期与数量覆盖保留，来源失败不错误派工。
- 同订单同工厂全部待派工明细通过才自动派工，不同工厂独立；新接入工厂在后续任务中按规则处理。
- 人工撤回暂停自动派工，手动再派与自动任务不重复记数量或发送通知。
- 任务调度、重试、中断恢复、首轮存量承接及真实来源调用量有证据；旧候选网页入口退役，兼容 API 与历史审计按当前契约核验。

## 变更完成标准

执行流程与授权按根目录 [AGENTS.md](../../../AGENTS.md) 和 [Issue tracker](../../agents/issue-tracker.md)；每项增量在开工前明确范围、依赖、数据影响和验收。

- 数据库验证空库迁移、存量承接与模型一致性；权限、事务、数量、并发和幂等使用隔离 MySQL。
- 接口变更同步 OpenAPI 和两客户端类型；受影响端完成相称检查、构建及约定的原型／真机验证。
- 合同、清单、质检文件核对原件完整性、权限和实际 Excel/WPS 行为；通知核对真实接收结果。
- 发布按精确提交核验 PR 与 main CI；环境部署、迁移、小程序及真实外发遵守具体授权。
- 修改文件、提交、验证证据和未完成边界记录在对应 Issue；系统签收及恢复演练记入[验收记录](../../shared/delivery/验收记录.md)。
