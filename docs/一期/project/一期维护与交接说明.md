## 接手阅读顺序

1. 阅读 [项目规则](../../../AGENTS.md)、[文档索引](../../README.md)、[里程碑](一期里程碑与决策记录.md)，检查 `git status` 与分支／HEAD。
2. 阅读 [需求 V1.60](../requirements/一期需求文档.md)、[领域术语](../../../CONTEXT.md)，确认本次业务与验收边界。
3. 阅读 [技术设计](一期技术设计方案.md) 的当前实现对照，再按任务查看[数据字典](一期数据字典与关系图.md)及[API 使用说明](一期API使用说明.md)。
4. 查对应 Issue、前置依赖、批准原型和已有测试，按仓库规则确定是否需要独立分支或 Worktree。
5. 涉及交付时读取[验收矩阵](一期验收与需求追溯矩阵.md)、[版本记录](一期版本发布记录.md)及[运维手册](一期部署与运维手册.md)。

| 位置 | 职责 |
