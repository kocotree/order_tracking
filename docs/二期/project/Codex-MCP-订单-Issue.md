## 范围

- [ ] 候选获取、状态、列表/详情/审计、字段保存、导入、排除；手工草稿创建、编辑、发布、删除。
- [ ] 未派工明细维护、来源预览/确认、选中明细派工预览/确认、按工厂撤回、完成及带原因重开。
- [ ] 合同资格查询、生成、重复导出及受权下载，复用稳定编号和快照。
- [ ] 复用事务、版本、幂等、采购关联和通知；工厂按稳定 ID/正式关联匹配，日期来自用户输入、附件或指定可靠来源。
- [ ] 来源更新应用预览快照；额外数量变化、未授权覆盖或歧义由对话展示差异确认。服务端强制权限及业务校验，模型 confirmed 不能证明用户授权。
- [ ] 批量默认全部预检，任一不合格即停止；明确允许部分执行才处理合格项。中断报告实际结果，超时先核实或原幂等键重试。
