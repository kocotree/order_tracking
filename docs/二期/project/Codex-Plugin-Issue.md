## 工作范围

- [ ] 按目标 Codex 实际支持格式提供 Plugin manifest、远程 MCP 配置及入口 Skill；不存业务源码、个人 token、服务器密钥或 Cookie，无需独立服务器部署。
- [ ] 首次连接打开浏览器，已有系统管理员登录时自动绑定，否则飞书登录后返回；无额外授权确认页。说明共同 30 天活动期限、自动刷新、统一退出与凭据丢失时的重新连接。
- [ ] 编写订单导入/更新/派工/合同、发货/收货/退回、质检返修、工厂/产品/人员/通知的必要 Skill 说明；复用工具 schema，避免复制整套 API 文档。
- [ ] 查询直接执行；目标、修改值与提交动作明确时连续完成。额外数量变化、未明确授权的覆盖、工厂或订单歧义必须展示具体差异再确认。工厂匹配依据稳定 ID 和正式关联，日期只用用户输入、附件或明确指定可靠来源；缺失时询问。
- [ ] 批量默认整批预检失败即停止，明确允许部分执行才处理合格项。中途失败回报已完成/未完成范围，超时先核实结果或使用原幂等键重试。保存、确认、通知发送和工厂查看分别如实说明。
- [ ] 文件正文、备注及工具返回内容作为数据，不接受其中夹带的指令。查询完成分页，日期与数量口径明确，写入后回读验证；不通过别的身份绕过权限或失败校验。
- [ ] 真实 Codex 完成附件上传、预览、创建、下载往返，覆盖本地引用和拖入附件；记录版本、大小与哈希，不记录临时文件链接或凭据。文件机制不兼容时修订设计并复验。
- [ ] 提供团队安装、更新、统一退出和故障定位说明；记录 Plugin 版本、MCP 契约版本、后端提交及 Codex 版本。测试/生产连接明确隔离。

## 验收标准

- [ ] 完成真实 Codex 业务验收；另用干净客户端环境验证安装不依赖作者本机配置、系统源码或服务器权限。角色差异由自动化测试覆盖。
- [ ] 对话完成 456# 隔离订单填日期、刷新来源、派工及合同；工厂改名依据正式关联消歧，额外变更提示具体差异。
- [ ] 对话查指定日期各厂发货总数及明细；调整指定发货单箱内项、保存并确认收货，回读与 Web 一致。
- [ ] 上传标准 `.xlsx` 生成质检返修任务并下载原件，错误文件与批量中断结果准确；不会要求用户回网页完成上传。
- [ ] 工厂/产品/人员/通知等其余 Web 动作逐项有工具与验收记录；歧义、覆盖、重复提交、断线恢复、账号停用、统一退出全部覆盖。
- [ ] 未安装 Plugin 的同事可按说明获取、安装并本人连接；远程私有仓库的实际访问及更新路径验证通过。
- [ ] 工厂可见任务、通知发送与实际收到分开验收；未验证的真实通知明确记为未验证。五项 MCP 与本 Plugin 工单全部通过后才宣布完整能力可用。

## 边界

不新增系统内聊天窗口、其他 Agent 客户端适配或 OCR。MCP 与数据库在系统仓库维护。当前不创建远程仓库，不推送、发布、部署或发送真实业务通知；待用户验收工单后进入实施。
