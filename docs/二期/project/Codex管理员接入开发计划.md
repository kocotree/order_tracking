## 2. A01：本人授权与订单查询闭环

**交付目标：**测试管理员首次复用网页登录身份连接 Codex，以本人身份查到与 Web 一致的订单；任一端使用共同续期，并可统一退出 Web 与 Plugin。

- 建立 MCP SDK、ASGI 挂载、生命周期、配置关闭开关与 Nginx 路由；使用既有业务服务实例。
- 增加技术设计第 3 节共同授权及四张 OAuth 表、现有 Web 会话关联迁移，接通飞书登录、PKCE、两端独立凭据签发/轮换、共同有效期与每请求账号检查；兼容迁移只关联现有有效会话。
- 修改 Web 登录、访问、刷新和退出链路：有效使用更新共同活动时间，两端刷新依据共同 30 天期限；统一退出/撤销原子失效父授权。同步 Cookie 保留策略、区分用户有效活动与后台保活；复用登录衔接并调整两端退出文案。
- 完成 `get_me`、`get_dashboard`、`list_orders`、`get_order`、`get_order_audit`、`logout_shared_session`。
- 建最小可安装测试 Plugin 和入口 Skill，固定真实 Codex 版本、预注册 client ID 配置、安装与 OAuth 联调证据。
- 抽取已被这条查询链实际需要的共享权限校验，验证原 Web 调用无行为变化。

**验收：**普通/最高管理员同数据查询；工厂和停用账号拒绝；错误 audience、PKCE 错误、回调不匹配、code 重放、refresh 重放拒绝；服务重启后查询与授权状态正确；Nginx 代理后的 MCP 初始化通过。

**共同授权专项：**

- 已登录 Web 首次绑定无需重复飞书登录；短期访问令牌到期时自动刷新，不重复要求授权。
- 只使用 Web 超过 30 天，仍持有刷新凭据的 Plugin 可以续期；只使用 Plugin 时同样维持 Web 的服务器授权资格。两端都没有有效活动 30 天则一起失效，单纯后台刷新不延长。
- 从 Web 退出或从 Plugin 统一退出，均使同账号关联 Web 会话与 Plugin grant 失效；不同账号不受影响。停用同样生效，旧 access 即使未到期也被拒绝。
- 重新登录产生新共同授权，旧 token/grant 不复活；多设备绑定、刷新与退出并发无撤销覆盖，过期请求不更新活动时间。
- 迁移不恢复过期/撤销会话、不重置闲置时限；客户端凭据清理后要求恢复身份，不能凭用户名登录。验证浏览器 Cookie 保留及下载登录恢复，小程序既有会话回归通过。

**文件范围：**`server/app/mcp`、`identity_access`、模型与迁移、`main.py`、授权 API、现有网页登录衔接与退出文案、`admin-web/nginx.conf`、依赖锁与测试；Plugin manifest、连接及初始 Skill。

**阻塞处理：**目标 Codex 无法使用预注册客户端时，提交兼容证据并修订认证设计；A02–A06 不建立在未验证的登录方式上。

## 3. A02：Excel 上传、质检返修与附件交付闭环

依赖 A01。**交付目标：**管理员在 Codex 交入 `.xlsx`，完成校验、确认创建、查询周期和下载原件，工厂任务按现有业务生成。

- 先验证原生文件参数在本次私有 MCP 和目标 Codex 上可用，覆盖拖入附件与本地文件引用；验证 20 MiB 文件及 20 份批次边界。
- 实现文件引用下载的 HTTPS 主机限制、网络地址限制、禁止越界重定向、流式大小与超时限制；复用现有 workbook parser 和私有文件存储。
- 完成 `list_repair_periods`、`get_repair`、`upload_repair_workbook`、`get_repair_preview`、`confirm_repair_previews`、`archive_repair_period`。
- 完成对话文件链接直达下载和失去网页登录时的安全恢复；补充质检 Skill。
- 批量先全部预检，未明确允许部分执行时有错误即不创建；提交中断逐份报告，并复用每份幂等键恢复。

**验收：**标准、损坏、非 `.xlsx`、超限、供应商匹配失败、同批部分失败、重复提交、预览过期、原件下载、整周期归档；创建前后周期数量及工厂可见任务与 Web 相同；记录文件往返实际字节大小与哈希，不记录临时下载链接。

**文件范围：**MCP 返修工具、文件下载适配、必要 API 文件跳转、返修幂等/批量复用、工具测试和 Plugin Skill。

**阻塞处理：**原生附件方案不能满足目标 Codex 时，必须修订文件技术设计并验证；本片不能以“用户回网页上传”作为完成条件。

## 4. A03：候选导入、派工、订单生命周期与合同闭环

- 完成手工草稿创建、编辑、发布、删除；来源明细模式按当前规则单独走派工流程。
- 完成未派工字段维护、来源预览/确认、派工预览/确认、按厂撤回、完成与撤销完成。
- 完成合同资格查询、首次生成、重复导出和文件交付。
- 补订单 Skill，明确真实采购关联、工厂名称消歧、人工最终日期、来源覆盖保护、整批目标与中途停止。
- 为所触及入口补齐幂等/版本缺口，共用业务事务内校验；不复制前端数量计算到 MCP。

**验收：**“456# 补日期并全部派工”的隔离样例；缺工厂/缺日期阻塞；来源更新后应用同一快照；同厂分批、全部/部分选择、版本冲突、重复派工、撤回限制、完整交货后完成、带原因重开；合同重复下载快照和编号稳定。来源外部读、写业务事实、工厂通知分别核验。

**文件范围：**MCP 订单/候选/合同工具，现有 order、order_import、contract service 中必要共享校验及事务改动，测试、Skill。

## 5. A04：发货查询、收货差异与退回闭环

依赖 A01、A02。**交付目标：**对话查各厂当日发货明细、下载两类清单、逐箱修改数量并确认收货或按单退回。

- 完成发货列表筛选/排序/分页、详情、关联订单、箱内项、凭证和操作记录。
- 把现有日汇总导出的查询提取为确有两个调用方的共享读取，结构化汇总与 Excel 均使用它；显式标明原报和上海业务日期。
- 完成单张与同厂同日 Excel 下载、收货草稿读写与确认、按发货单规格退回。
- 补发货/收货 Skill，含列表当前数量与日汇总原报数量的区分、明确用户提问口径、保存和确认的实际效果。

**验收：**同厂多单、跨厂、撤回/作废、重新提交跨日、跨日确认、退回、导入初始已发；统计与相应 Web/导出逐项一致。逐箱修改不误改同 SKU 其他箱；确认只生效一次；多人核对冲突；保存未确认不改变业务数量；确认后回读订单数量与发货单收货状态。

**文件范围：**MCP 发货工具、现有 shipment 共享查询/收货事务中必要改动、测试及 Skill。

- 完善对应 Skill 和工具描述；重新核对能力表的全部页面、按钮、禁用条件及分页选项。已进入 Web 的二期新增动作按其服务契约接入，并注明所属 Issue 依赖。

**验收：**工厂名/编号唯一、不可改字段、合同资料校验、产品只读；普通管理员/最高管理员/工厂/停用账号的完整权限组合；目标人员歧义、审核并发、最高管理员不可被停用；通知已读仅影响本人。禁止“修复派工问题”隐含授权停用用户或改变角色。

## 7. A06：跨入口验收、团队分发与发布准备

依赖 A01–A05 全部通过。**交付目标：**无项目源码和服务器权限的同事仅安装、本人授权后即可完成完整业务任务。

- 为能力表每行逐动作登记 MCP 工具、测试名称和 Web/Codex 验收证据；缺项必须补齐。保存后端提交、工具契约版本、Plugin tag 和 Codex 版本配对。
- 在隔离环境执行正常、歧义、失败、重复提交、并发及断线恢复任务；角色差异由自动化测试覆盖，验证报错后不会通过其他身份或接口继续。
- 完成 Plugin 私有分发渠道、安装、更新、撤销、故障定位说明；验证同事账号能够获取插件和完成文件往返。安装需要的仓库访问由团队分发安排解决，不要求业务同事获得系统源码权限。
- 验证 API/worker/nginx 部署组合、授权表迁移、关闭 MCP 的恢复路径和日志脱敏；复核两个环境独立 origin、DB、凭据和文件存储。
- 按项目要求完成 PR 全 CI、审查、合并后 `main` 全 CI，形成版本发布候选。版本标签、共享测试部署、真实通知及生产验收按各自已有授权范围执行；需新增授权时展示具体目标与影响。

**验收产物：**完整能力矩阵、端到端结果、安装说明、版本兼容表、迁移/恢复记录、发布检查与遗留问题。没有验证的真实工厂通知只注明未验证，不写“工厂已收到”。

## 8. 各片共用检查与完成标准

| 检查 | 要求 |
|---|---|
| 数据库 | 显式设置隔离的 `ORDER_TRACKING_DATABASE_URL` 和 `ORDER_TRACKING_TEST_DATABASE_URL`；迁移可重现，与来货出入任务的测试库隔离 |
| 后端 | 复用现有 pytest，核心权限/事务/数量优先 TDD；Ruff、mypy、OpenAPI 一致性及受影响业务回归 |
| 网页 | 修改现有登录衔接和退出文案时执行相关 lint、类型、组件测试、构建及实际浏览器验证 |
| MCP | 测试协议初始化、工具 schema、身份隔离、正常与错误返回、原始异常脱敏；工具权限在直接调用时仍强制执行 |
| 文件 | 原件完整性、格式/大小限制、受权下载、失效链接、SSRF 防护、Codex 实际接收/交付 |
| 幂等与并发 | 同键重放无重复副作用，同键异参拒绝；版本冲突无覆盖；批量中断真实报告 |
| Git/CI | 五项 MCP、一项 Plugin 各在所属仓库按独立分支/PR 交付；后端及部署修改遵循完整远程 CI，普通本地通过不表示可发布 |
