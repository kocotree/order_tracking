## 固定样本回归

运行 `uv run python -m scripts.incoming_diff_regression <实验目录>`。脚本复用实验 `score.py` 的人工标注读取、字段判分、差异行判分和稳定性计算，只接受 `s1_35flash_v12_boxes` 的三个已有运行结果，并核对提示词哈希、样本与结果完整性。实验目录被 Git 忽略，输出位于其 `out_fixed_v12/field_results.csv`、`errors.csv` 和 `report.md`。

本机样本结构检查：36 张图片均有人工标注，空标注 0；每图 3 次，共 108 条历史运行结果。与现有人工标注严格一致的结果：工厂名 105/108（97.2%）、货号 105/108（97.2%）、品名 104/108（96.3%）、差异行颜色/尺码/方向/数量整体 95/108（88.0%）；同图三次结果完全稳定 22/36（61.1%）。逐字段错误共 23 条，例如 `img049` 的 F 尺码缺失、`img050` 的一条蔚海蓝颜色缺失、`img057` 的工厂/货号/品名未识别且尺码错误。`boxes` 和 `diffNoteText` 缺少完整人工真值，不计准确率。上述数字来自本地已有原始运行记录，本次未调用模型；人工标注的图像语义未重新核验。
