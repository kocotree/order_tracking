## 已确认的实施边界

- 来货出入复用数量台账，采购子单必须唯一关联系统订单明细与 SKU，发货单可空；识别结果只作候选，正式登记须管理员明确确认。
- 原型只覆盖管理员订单详情与工厂任务详情；飞书侧使用需求附录的消息卡片文案及真实 Excel 样例，不制作聊天 HTML 页面。网页表格为 7 列，工厂端无记录时隐藏整区。
- Issue #239 已取消最终 Excel 对原批次、文件名、版本、签名及逐行标识的依赖，支持跨批次合并和按厂拆分。原图长期保留，数量纠正使用差额调整，不删除已登记记录；自由整理后的来源通过原始文件、Sheet 和行号追溯。
- 识别固定使用 `qwen3.5-flash` 和 `single_v12_boxes.txt`，不识别图片日期。#208 增量随 PR #209 进入 v1.1.6：颜色直接连接尺码、原图嵌入、全派工状态采购匹配及未派工登记；唯一候选忽略未发数量，多候选沿用已确认选择规则。
- Codex 使用已启用管理员本人身份，复用网页登录及共同授权，无额外授权确认页或客户端管理页；业务上传仅支持 `.xlsx`。新增 Web 能力须同步核对 MCP 覆盖。
- 箱贴独立于来货出入需求，复用订单、工厂、SKU 图片及私有文件；图片数据准备依赖 #188，导出范围按 #186。
- 仓库员工入口、价格金额、付款、工厂／SKU 周汇总导出不在已批准范围；未批准业务线按各自确认门推进。

## 周出货回填的已确认规则

2026-10-06 确认：按工厂正式提交的正常发货原报数量汇总，排除截止前撤回和作废，不扣退回，不含初始基线、收货差额及其他数量调整。该口径替换2026-09-11记录的笼统“系统有效出货”表述。

从10月6日开始，10月沿用现有阶段；11月起按月内周段划分，月初/月末1～2天并入相邻阶段，3天及以上独立。每阶段末日北京时间22点截止，之后发货连续计入下一阶段，包括跨月；月初建齐当月列并扩展总数公式。Issue #246 调整为仅向空白单元格写入绝对合计，已有值含0一律跳过；根发货单去重、冻结后不业务重算，每次执行留日志。飞书并发编辑限制见技术设计。

完整范围、例子和验收见[独立需求](../requirements/出货阶段汇总回填需求.md)。订单来源字段继续只读，本功能的阶段数字列与总数公式为有限回填例外。代码已进入 main；运行、真实回读与启用授权分别核验，结果见交付清单。
