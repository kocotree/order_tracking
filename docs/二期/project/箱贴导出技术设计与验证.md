# 箱贴导出技术设计与验证

## 实现

- 页面复用合同弹窗外壳与表格样式，仅新增已确认的按钮、四列及加载、空值、失败反馈。
- 颜色提取复用已合并 #189 的 `server/app/modules/product_sync/color.py`；真实旧规格 `红色120/60` 的整体尺码和“无尺码”在公共函数中补齐，使合同与箱贴共用同一规则。
- `GET /api/v1/admin/orders/{order_id}/box-labels` 读取现有订单明细或历史派工行，返回分组和待补齐行；`POST .../{group_id}/exports` 首次生成；`GET /api/v1/admin/box-label-exports/{export_id}/download` 下载。写请求校验 Web 会话和 CSRF，三条接口均验证已启用管理员身份。
- `box_label_exports` 每个订单分组唯一，保存首次成功的文字快照、模板版本及 `stored_files` 关系。订单行锁串行化同订单首次导出；同时锁定已存在导出记录，兼容 MySQL 默认 `REPEATABLE READ`。上传成功但事务失败时删除新对象；图片读取或生成失败时事务不落库。
- 图片只取当前组的 `ProductVariant.cached_image_key`，先按 SKU 编码排序；有来源而缓存未完成的组不固化空图。下载读取固定工作簿并核对 SHA-256，不依赖后续可覆盖的 SKU 图片路径。
- 模板由最终用户文件脱敏生成，仓库路径为 `server/app/templates/box_label_v1.xlsx`。已清除两张示例图及两份工厂、货号、品名、颜色示例值，保留字段名、合并区域、边框及打印设置；正式运行仅读取仓库模板。
  原始文件 SHA-256 为 `9b76e3a1687606f9b09fabdd5a5f6d9c365246d183adb4d444aa137c4764721b`；仓库脱敏 v1 文件 SHA-256 为 `e19cf44f70ae3389905995af37ebd5fe3c4676887eb2001646ef58be7d97d8d3`。

## 验收边界

已读取现有订单详情原型脚本、公共组件、表格样式和正式页面；当前用户规则禁止主动视觉功能，因此未执行浏览器并排视觉核验。WPS/Excel 原生打开及打印完整性仍待具备相应应用的环境验收。生产首次导出仍以 SKU 图片数据验收为前提；本地测试、PR CI 和生产业务验收分别记录。
