# 新发货退回同步增量

Issue #258。用户已确认本增量的业务口径；部署与启用仍按生产发布门执行。

现有出货阶段原报回填规则保持默认行为。新增只读、显式启用的净出货接口，仅对固定生效整点后首次正式提交的正常发货单，按明细扣除实际退回数量。生效点前的发货和历史退回不追溯，生效时当阶段已同步数量保持原口径。

部分退回扣对应数量；全部退回为零。跨阶段退回修正来源发货阶段，不能扣到退回发生阶段。新的补发单在其正式提交阶段计入。同一根单撤回重提继续遵循阶段结算及去重，不因重提重复统计。规格数量超过原报的异常退回停止回写，禁止生成负出货值。

新接口与现有工厂任务数量台账分离，不修改原报、确认、退回或派工记录，不产生通知、发货或退回测试业务。来源身份丢失、重复或变化时停止。

消费端继续只更新已接管且未被人工改动的单元格；人工值保留并记录差异。生效时间固定保存；接口与消费配置不一致时停止。消费游标只在整包全部阶段完成后前进，失败、待确认或忙碌时保留，重复执行不重复扣减。

验收覆盖边界、历史隔离、部分/全部退回、跨阶段和跨月、补发、撤回重提、人工编辑、写入响应丢失、游标恢复及默认接口兼容。先副本验证，再按授权启用原表。
