# 二期箱贴导出需求

> 2026-09-29；独立业务线；执行范围与验收以 [Issue #186](https://github.com/kocotree/order_tracking/issues/186) 为准。

管理员网页订单详情右上角显示“导出箱贴”。点击后始终显示四列表格：工厂、产品名称、颜色、操作。当前订单按系统工厂 ID、产品 ID、颜色合并，不按产品名称合并；同组不同尺码只占一行。未关联工厂的明细不展示。有工厂但产品未匹配或颜色无法确定的明细保留一行，操作显示“产品未匹配”或“颜色无法确定”，禁用导出。空列表显示“暂无可导出的箱贴”。所有订单状态均可使用；普通管理员和最高管理员沿用 Web 会话权限。

颜色从当前订单明细的颜色/规格取值提取。2026-09-29 只读核对聚水潭真实样本：`KQ26168` 的 `冰川蓝110/120/130`，`KQ131212` 的 `粉色;XL`，`KQ16117` 的 `咖啡;`，`TJ2179` 的 `红色120/60`；项目现有真实格式测试样本还包含 `米色 / 52cm`。规则依次处理分号、空格斜杠、末尾的均码/无尺码/字母尺码/两至三位数字尺码及可选体型后缀。颜色中间的数字保留；无法按已知格式确定的值提示补齐，不能任意截断。

一行直接下载 `.xlsx`。文件名为 `订单编号_工厂简称_产品名称_颜色.xlsx`，非法文件名字符替换为 `_`。采用用户最终文件“暖呼吸羽绒马甲冰川蓝.xlsx”的脱敏 `v1` 模板：一页上下两张箱贴，位于 `A1:E8` 和 `A11:E18`，打印区域 `A1:E18`；保留边框、合并单元格、空格结构及“尺码”字段。只填工厂、货号、品名、颜色；尺码、装箱数量、发货日期、箱号/总箱数始终空白。

组内按 SKU 编码升序选择第一个已有可用缓存图片的 SKU，等比例放入两张箱贴。确实没有图片来源时允许空图；图片来源尚待缓存、已报错或 OSS 读取失败时导出失败并允许重试。成功导出的工作簿、文件名和模板版本按订单及分组固定在私有文件存储，之后资料变化仍返回同一文件；并发首次导出只能产生一个结果，失败不能留下正式快照。

正式首次导出前须单独验收 #188 的生产 SKU 图片数据：核对目标 SKU 的来源图、缓存状态、OSS 读权限、代表图颜色及已存在的错误货号级旧图。OSS 访问恢复本身不证明补齐完成。本需求不包含生产部署、迁移、旧图补齐、小程序、PDF、批量导出或真实通知。
