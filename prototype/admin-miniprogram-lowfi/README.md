# 管理员小程序低保真原型

本目录用于逐页确认管理员小程序的页面、字段和操作顺序，不是微信小程序正式实现代码，也不需要微信开发者工具运行。可以直接双击 `index.html` 查看，也可以通过本地服务器打开。

## 当前范围

- 已制作：订单列表页、订单详情页、只读发货单详情页。
- 已实现：订单编号、产品名称、颜色/规格搜索；订单状态、工厂多选、跟单人员、合同出货时间、仅看逾期和排序筛选；筛选重置；空结果状态。
- 已体现：订单主状态与逾期提醒分开、合同出货时间、发货进度、已发数量与订单数量。
- 订单详情已实现：只读展示订单摘要、单一合同出货时间、发货进度、工厂下单/已发/未发数量、工厂产品名称、颜色规格及已出/下单数量和关联发货单。
- 底部导航按 V1.30 使用“订单、发货、我的”；管理员小程序统一只读查看订单、发货记录和返修进度，正常发货不设置待收货角标。
- 尚未制作：发货板块、返修进度详情、我的和进入权限状态。

## 本地查看

```bash
cd prototype/admin-miniprogram-lowfi
python3 -m http.server 4174
```

浏览器打开 `http://127.0.0.1:4174/`。

## 原型边界

- 订单卡片可以进入订单详情，关联发货单可以进入只读发货单详情；点击“发货”或“我的”时仅提示后续逐页确认，不提前制作未确认页面。
- 正式开发将在 `miniprogram/` 中建立微信小程序项目，本原型不会直接作为生产代码上线。

## 文件边界

- `scripts/app.js`：只负责原型状态、公共方法和页面切换。
- `scripts/mock-data.js`：订单、筛选项和订单详情模拟数据。
- `scripts/icons.js`：页面共用图标。
- `scripts/pages/`：每个已确认页面的渲染与交互实现。
- `styles/tokens.css`：颜色、字体和阴影变量。
- `styles/base.css`：重置样式和跨页面公共样式。
- `styles/order-list.css`、`styles/order-detail.css`、`styles/shipment-detail.css`：各页面独立样式。

为兼容直接双击 `index.html`，原型继续使用按顺序加载的普通脚本，不使用 ES Module 或构建工具。
