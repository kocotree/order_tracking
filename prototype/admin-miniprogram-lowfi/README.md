# 管理员小程序低保真原型

本目录用于逐页确认管理员小程序的页面、字段和操作顺序，不是微信小程序正式实现代码，也不需要微信开发者工具运行。可以直接双击 `index.html` 查看，也可以通过本地服务器打开。

## 当前范围

- 已制作：管理员账号首次绑定与权限状态页、订单列表页、订单详情页、发货记录列表页、只读发货单详情页、返修进度列表页、只读返修详情页和“我的”页面。
- 进入与权限状态已实现：微信身份由小程序静默识别；尚未绑定时展示带 KOCOTREE 标识的手机号授权页，通过微信授权手机号匹配网页端已验证的管理员申请，不在小程序填写姓名或提交管理员申请；另包含身份识别中、审核中、申请未通过、未匹配、无法唯一匹配、账号停用和已退出登录状态，匹配已通过账号或重新登录后进入订单首页；身份状态页不显示业务底部导航。
- 已实现：订单编号、产品名称搜索；“未完成、已逾期、已完成”订单状态、工厂单选、跟单人员、合同出货时间和排序筛选；筛选重置；空结果状态。
- 已体现：订单正式状态按合同出货时间自动区分未完成与已逾期，并展示发货进度、已发数量与订单数量。
- 订单列表卡片支持点击整张卡片进入详情；订单详情只读展示订单摘要、单一合同出货时间、发货进度、工厂下单/已发/未发数量；工厂卡片默认折叠，点击整张卡片展开产品名称、颜色规格及已出/下单数量，并展示关联发货单。
- 发货单详情已实现：发货概览、按订单默认折叠的发货明细、默认全部收起的逐箱装箱明细、发货凭证、工厂备注和操作记录；装箱明细将订单编号跟在产品名称后，不展示产品图片、产品编码或管理操作。
- 发货记录列表已实现：按订单编号或产品名称搜索，按工厂单选和发货日期范围筛选；卡片标题同行展示产品摘要和完整订单编号，包含多个产品时显示“首个产品名称等 N 个产品”，多个订单编号全部展示并用顿号分隔，右侧只保留进入箭头；辅助展示工厂、发货单号、发货日期、发货数量和总箱数，并可进入只读发货单详情。
- 返修进度列表已实现：只按工厂名称搜索，按“未完成、已完成”状态、工厂单选和退回日期范围筛选；每张卡片以工厂为单位汇总该返修单内的产品，突出状态、产品摘要、待返回数量和返回进度，辅助展示返修数量、报废数量及返修单号。
- 返修详情已实现：顶部展示“未完成、已完成”状态、工厂、返修单号、退回日期、返修数量、报废数量和返回进度；下方使用“质检明细、工厂发回记录”两个页签，质检明细按产品折叠，发回记录按日期折叠并在展开后按产品分组，各规格使用进度条展示返回进度；不展示质检单附件或照片。
- “我的”已实现：默认展示微信头像，点击头像后从底部选择“查看头像”或“更换头像”，更换结果仅在小程序端使用且不覆盖网页端飞书头像；展示姓名、管理员类型和账号状态，并提供新订单、临期逾期、正常发货和质检单返修四项业务通知开关；微信通知未授权时在对应业务行提示并提供开启入口；页面底部可二次确认退出登录，退出只清除会话、不解除账号绑定，不提供姓名等其他资料编辑或解除绑定。
- 底部导航按 V1.30 使用“订单、发货、我的”；管理员小程序统一只读查看订单、发货记录和返修进度，正常发货不设置待收货角标。

## 本地查看

```bash
cd prototype/admin-miniprogram-lowfi
python3 -m http.server 4174
```

浏览器打开 `http://127.0.0.1:4174/`。

## 原型边界

- 订单卡片可以进入订单详情；订单详情中的关联发货单和“发货—发货记录”列表均可进入只读发货单详情；“返修进度”列表可以进入只读返修详情；底部“我的”进入个人中心页面。
- 正式开发将在 `miniprogram/` 中建立微信小程序项目，本原型不会直接作为生产代码上线。

## 文件边界

- `scripts/app.js`：只负责原型状态、公共方法和页面切换。
- `scripts/mock-data.js`：订单、筛选项、订单详情和发货单模拟数据。
- `scripts/icons.js`：页面共用图标。
- `scripts/pages/`：每个已确认页面的渲染与交互实现，其中 `auth.js` 负责管理员账号首次绑定和权限状态。
- `styles/tokens.css`：颜色、字体和阴影变量。
- `styles/base.css`：重置样式和跨页面公共样式。
- `styles/auth.css`、`styles/order-list.css`、`styles/order-detail.css`、`styles/shipment-list.css`、`styles/repair-list.css`、`styles/repair-detail.css`、`styles/shipment-detail.css`、`styles/profile.css`：各页面独立样式。

为兼容直接双击 `index.html`，原型继续使用按顺序加载的普通脚本，不使用 ES Module 或构建工具。
