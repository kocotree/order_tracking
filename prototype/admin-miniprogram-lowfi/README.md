# 管理员小程序原型

本目录保留管理员小程序的浏览器交互原型，使用模拟数据。现行入口见[三端页面地图](../../docs/一期/project/一期三端页面地图.md)，业务规则见[一期需求及增量](../../docs/一期/requirements/一期需求文档.md)，正式工程见[miniprogram](../../miniprogram/README.md)。

## 本地查看

```bash
cd prototype/admin-miniprogram-lowfi
python3 -m http.server 4174
```

浏览器打开 `http://127.0.0.1:4174/`；也支持直接打开 `index.html`。原型使用按顺序加载的普通脚本，无需构建。

## 内容与文件

- 页面包括身份与权限、订单列表／详情、发货记录／详情、返修进度／详情、我的及通知；管理员业务操作以移动只读查询为边界。
- `scripts/app.js` 管理状态与切换，`mock-data.js` 提供模拟数据，`icons.js` 管理图标，`pages/` 包含页面交互。
- `styles/tokens.css` 和 `base.css` 为公共样式，其余样式按页面组织。
- Issue #240（2026-10-10）：正常发货由后台自动收货，小程序不展示收货状态、确认人／时间或“系统自动确认”；现有发货列表和详情原型已无上述内容，不新增对应区块。后台收货事实、最新有效数量、历史记录和订单关联入口保留；收货通知删除，实际装箱修改通知保留。正式工程现有收货确认提示及专用展示代码按技术设计删除。

## 使用边界

原型含历史单一合同日期及单返修单等交互，不能据此覆盖后来确认的明细日期和返修周期规则。正式页面实施前对照当前需求、[小程序复刻规范](../../docs/shared/小程序原型复刻规范.md)和本次确认范围；有意差异须记录。

浏览器演示不连接真实 API、数据库或微信身份，也不能验证原生手机号／订阅授权、真机文件及正式发布。实际终端验收见[验收记录](../../docs/shared/delivery/验收记录.md)。
