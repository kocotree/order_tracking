# 管理员网页端低保真原型

本目录只用于逐页确认跟单管理系统管理员网页端的页面、字段和操作顺序，不是正式实现代码。

## 当前范围

- 已实现：公共侧栏、顶部栏、订单看板、订单与发货下的“订单列表”初版。
- 已实现交互：看板搜索、订单列表状态与高级筛选、排序、重置、当前一级导航重复点击展开/收回二级侧栏、通知面板、待设计页面提示。
- 订单正式状态统一为“未完成、已逾期、已完成”，草稿单独保留；返修状态只使用“未完成、已完成”。订单和返修列表、筛选与详情使用同一口径。
- 待导入订单页保留“待处理、已导入”两个页签；管理员点击“获取飞书新订单”模拟增量获取，页面展示加载防重复点击、获取结果和上次成功获取时间。获取只生成或更新待处理候选记录，确认导入后生成草稿订单，不代表订单已经发布。
- 本目录只模拟页面和交互，不连接飞书或真实数据库。

## 当前视觉约定

- 亮蓝应用栏顶部使用 KOCOTREE 紧凑 Logo；白色展开栏只显示系统名称“跟单管理”，不重复 Logo。
- 严格沿用用户提供的聚水潭 ERP 参考：亮蓝应用栏、白色页面菜单、浅灰工作区、纯白内容块和亮蓝主操作。
- 五个一级入口固定放在亮蓝应用栏，白色展开栏只承载当前一级入口的二级页面。
- 桌面端二级页面栏可以折叠，折叠后仍保留全部一级入口。
- 订单看板使用三个统计卡片＋右侧“最近通知”的摘要布局，不展示单独的“待处理事项”列表，也不为作废申请单独设置统计卡。
- 三个统计卡片只显示标题与大号数字；通知标题与说明同排并使用黑色圆点标记；订单表使用浅灰底深色粗体表头，仅整行左右两端保留边线，订单编号统一展示为“3 位数字＋#”。
- 看板订单表只展示产品名称，不附带颜色/规格数量摘要；跟单人员使用深蓝粗体；进度列采用“发货进度”和“已发 / 订单数”口径。
- “订单”区域采用无框线表格和舒展行高，行悬停使用浅蓝底；状态使用彩色圆点＋黑色文字，不使用胶囊底纹。
- “订单”标题使用 18px 粗体，排序说明紧随标题同排展示；订单编号使用与正文一致的字体并适当放大。
- 当前只设计管理员网页端；窄屏检查仅用于网页浏览器容错，不代表管理员小程序或工厂小程序原型已经开始。

## 本地查看

```bash
cd prototype/admin-web-lowfi
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173/#/dashboard`；订单列表为 `http://127.0.0.1:4173/#/orders`。

待导入订单：`http://127.0.0.1:4173/#/pending-imports`。

登录与访问申请原型：

- 飞书登录：`http://127.0.0.1:4173/#/login`
- 管理员申请：`http://127.0.0.1:4173/#/admin-apply`
- 审核中：`http://127.0.0.1:4173/#/access-status/pending`
- 已拒绝：`http://127.0.0.1:4173/#/access-status/rejected`
- 已停用：`http://127.0.0.1:4173/#/access-status/disabled`

## 文件边界

- `styles/`：公共令牌、布局、组件和当前页面样式。
- `scripts/components/`：所有页面共用的外壳和交互组件。
- `scripts/pages/`：每个页面单独一个文件。
- `scripts/mock-data.js`：原型模拟数据，刷新页面后恢复初始状态。

后续正式开发将在 `admin-web/` 中重新建立正式项目，本原型不会直接作为生产代码上线。
