# 工厂小程序原型

本目录保留工厂小程序的浏览器交互原型，使用模拟数据。现行业务见[一期需求及增量](../../docs/一期/requirements/一期需求文档.md)，入口见[三端页面地图](../../docs/一期/project/一期三端页面地图.md)，正式工程见[miniprogram](../../miniprogram/README.md)。

## 本地查看

```bash
cd prototype/factory-miniprogram-lowfi
python3 -m http.server 4175
```

浏览器打开 `http://127.0.0.1:4175/`。身份状态可用 `#auth=apply`、`#auth=pending`、`#auth=rejected`、`#auth=disabled` 预览；这些参数只用于原型检查。

## 内容与边界

- 底部入口为任务、发货记录、我的；任务包含订单与返修，详情只展示本厂数据。
- 正常发货演示箱号、订单规格、装箱数量、凭证／备注、预览提交；返修演示规格选择、返修／报废数量及发回记录。
- 我的包含身份、工厂、提醒授权、通知与退出；通知展示全部／未读和业务跳转。
- Issue #240（2026-10-10）更新发货提交及详情：后台提交自动收货，页面隐藏收货状态和确认信息，不展示“系统自动确认”，提交／重提提示及新增日志不强调自动收货；保留撤回、作废、退回和修改差异。撤回立即冲销模拟任务数量，同号继续修改并重提，首次提交满7天或已有退回禁止撤回。只读装箱展示保留，工厂不直接修改有效发货单。收货通知删除，实际修改通知保留；原型不发送通知。页面范围已授权，本轮更新后的视觉待用户查看。
- 演示时钟固定为2026-08-19 11:20（北京时间），首张记录可撤回并重提，8月10日记录超过7天；修改模拟数据的 `returnRecords` 可覆盖退回限制。刷新恢复数据，三端不互通，不发送通知。新提交与重提只演示内存状态，正式草稿持久化、附件上传和并发权限由后续正式工程实现。
- 原型仍含单返修单及早期装箱方案；返修周期、连续箱／尾箱等规则按正式需求核对，不能直接照搬旧文案。

实施时读取[小程序复刻规范](../../docs/shared/小程序原型复刻规范.md)及对应页面脚本和样式，按已确认范围复用。模拟提交、原生授权提示和下载演示均不能作为真实业务证据；验收见[验收记录](../../docs/shared/delivery/验收记录.md)。
