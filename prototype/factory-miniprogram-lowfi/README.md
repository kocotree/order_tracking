# 工厂小程序低保真原型

本目录用于逐页确认工厂小程序的页面、字段和操作顺序，不是微信小程序正式实现代码，也不需要微信开发者工具运行。可以直接双击 `index.html` 查看，也可以通过本地服务器打开。

## 当前范围

- 已制作：正常任务列表页（按产品规格展示，含搜索与筛选）。
- 已体现：下单数量、已发数量、未发数量、合同出货时间、进度条、逾期提醒、状态标签。
- 底部导航：任务、发货记录、我的。
- 已完成订单展示但排在后面。

## 确认顺序

1. ✅ 正常任务列表（当前页）
2. ⬜ 本厂任务详情
3. ⬜ 创建发货单流程
4. ⬜ 质检单返修任务列表与详情
5. ⬜ 发货记录
6. ⬜ 我的

## 本地查看

```bash
cd prototype/factory-miniprogram-lowfi
python3 -m http.server 4175
```

浏览器打开 `http://127.0.0.1:4175/`。

## 原型边界

- 任务卡片可以进入任务详情；点击底部其他页签时仅提示后续逐页确认，不提前制作未确认页面。
- 正式开发将在 `miniprogram/` 中建立微信小程序项目，本原型不会直接作为生产代码上线。
